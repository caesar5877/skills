# 术语表（glossary）

> 随 Skill 分发，用于回答"这个词在这本书里指什么"。
> 只收录**作者有特定用法**的词；页码为原书印刷页。

| 术语 | 作者的用法 | 与常识的差异 | 位置 |
|---|---|---|---|
| bamboo ceiling（竹天花板） | 亚裔晋升到影响力层级时的阻碍，由他人误读与自身文化行为共同构成；Tool 7 把它拆成组织性与个人性两栏 | 日常等于"种族歧视"；作者定义要求同时盘点个人侧 | p.132–133 |
| prewire（预连线） | 决策会前单独接触影响结论的人，打预防针、争取理解 | 不是拉帮结派，限于对 surprise 的预防 | p.234 |
| winner's file（成就档案） | 自己特别引以为傲的成果清单，绩效讨论时携带作为证据底座 | 比"剪报"更严格：服务薪酬/晋升对话，需与书面职责对齐 | p.252 |
| the three S's | 个人说辞的三条同时成立的约束：succinct / sincere / specific | sincere 项带明确禁令（不得借信息访谈要推荐） | p.181–183 |
| informational interview | 以了解领域/公司为目的的访谈；对话推进责任在发起方；与求职面试严格区分 | 常被当作要内推的前置动作——作者点名禁止 | p.182–184 |
| sponsor | 因资历或在遴选/继任委员会位置，能把你的名字放进候选池并背书 | 与 mentor 的区分是**能否改变机会集合** | p.216 |
| mentor | 周期性教练职场议题，可在司外 | 不等于"内部前辈" | p.216 |
| career buddy | 早你 1–2 年，解答流程与地雷（自评怎么填、调薪节奏、内部备忘格式） | 不是"关系好的同事"，而是流程情报源 | p.216 |
| ARM（Asian role model） | 提供"原来可以"的可见性来源，不必定期见面 | 不是导师；也可由非亚裔担任（作者举非裔同事例） | p.216–217 |
| token-Asian syndrome | 组织用个别可见的亚裔成员证明包容性，实质决策层未变 | 重点在该个体的**展示功能** | p.66 |
| model-minority myth | "亚裔已成功、无需帮助"的观念；代价包括掩盖数据缺口、切断跨族裔互助、压低期待 | 日常当作夸奖 | p.47–50 |
| perpetual foreigner syndrome | 数代居住仍被追问"really 来自哪里"，影响归属感与对外代表角色的适配预期 | 不是好奇心问题 | p.15–16 |
| cultural fluency / competency | 按场合开关或调节自身行为面向的能力，核心是"不必变成另一个人" | 常被误读为同化 | p.52–54 |
| assimilation vs. acculturation | 同化＝以自身文化特征为代价采纳主流；濡化＝采纳主流模式同时保留本族价值 | 日常混用为"融入" | 前言 p.vii |
| motivated skills | 从你愿意反复做、能讲出细节的故事中提炼的技能 | 差别在**来源**：故事证据而非自评形容词 | p.93–99 |
| career immobility / mobility signals | 以可观察信号判定（是否代表公司露面、是否入专项组、高层是否征求你意见、是否提前得知未来计划） | 不是主观"觉得停滞" | p.134 |
| shame-based culture | 失败被视为公开羞耻 → 回避冒险与暴露不完美 → 回避高可见度任务 | 不是"爱面子"的性格描述，而是成因链 | p.37–38, p.133 |
| homosocial reproduction | 管理者倾向提拔与自己相似者（引 Rosabeth Moss Kanter）；作者用以说明"选人者本身是干预点" | 不是"喜欢相似的人"，而是选拔环节的结构性偏差 | p.42–43 |
| succession planning pipeline | 组织为关键岗位储备接班人的流程；不在名单内绩效再好也无法兑换关键岗位 | 把晋升重述为流程内/外的二元位置 | p.216, p.232 |
| Asian-friendly employer | 可由可观察实务判定的雇主类型，并配套面试/网络场合的提问清单 | 不是"氛围好"，而是证据 + 提问清单 | p.58–62 |
| bicultural | 在家一套规范、在外另一套的长期切换状态，并延续到职场 | 不是"会两门语言" | p.228 |
| trademark value | 别人最记得你什么、你会用哪两个形容词描述我——由他人回答，不是自封 | 不是"核心竞争力"的自评版本 | p.110 |

## 使用提示

- 这些词**不是普适概念**：迁移到其他语境时需要重新检验作者的定义是否成立。
- 族裔相关术语（bamboo ceiling / model minority / perpetual foreigner / token-Asian）描述的是
  特定职场环境中的机制，**不得用于预测或评判具体个人**。
