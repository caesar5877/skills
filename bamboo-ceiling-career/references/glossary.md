# 术语表（glossary）

> 随 Skill 分发，用于回答"这个词在本能力集里指什么"。
> 以下定义**即本能力集内的定义**，自包含、不指向任何外部文献或量表；
> 只收录本能力集有特定用法的词，与日常含义不同时会写明差异。

| 术语 | 本能力集定义 | 与常识用法的差异 |
|---|---|---|
| bamboo ceiling（竹天花板） | 亚裔晋升到影响力层级时遇到的阻碍，由他人误读与自身文化行为共同构成；诊断时拆成组织性障碍与个人性障碍两栏 | 日常等于"种族歧视"；本定义要求同时盘点个人侧与结构侧 |
| 预连线（prewire） | 决策会前单独接触会影响结论的人，先打预防针、争取理解 | 不是拉帮结派或拉票，仅限于消除 surprise |
| 成果档案 | 自己特别引以为傲的成果清单，绩效讨论时携带作为证据底座 | 比"剪报"更严格：服务薪酬与晋升对话，需与书面职责对齐 |
| 个人说辞三条约束 | 自我介绍同时成立的三条约束：简短、真诚、具体 | 不是"电梯话术模板"，而是三条同时成立的检查项 |
| 信息访谈 | 以了解领域或公司为目的的访谈；推进对话的责任在发起方；与求职面试严格区分 | 常被当作要内推的前置动作——本能力集明确禁止这样做 |
| sponsor（赞助人） | 因资历或在遴选、继任委员会的位置，能把你的名字放进候选池并替你背书 | 与 mentor 的分界是**能否改变你的机会集合** |
| mentor（导师） | 周期性陪你处理职场议题的教练，可以在司外 | 不等于"公司里的前辈" |
| 同行搭子 | 早你 1–2 年、能回答流程与地雷的人（自评怎么填、调薪节奏、内部备忘格式） | 不是"关系好的同事"，而是流程情报源 |
| 榜样角色 | 让你看到"原来这样做可以"的人，不必定期见面 | 不是导师；也可由任何背景的人担任 |
| 象征性代表（token-Asian） | 组织用个别可见的亚裔成员证明包容性，实质决策层未变 | 重点在该个体的**展示功能**，而非其个人处境 |
| 模范少数族裔神话 | "亚裔已成功、无需帮助"的观念；代价是掩盖数据缺口、切断跨族裔互助、压低期待 | 日常被当作夸奖使用 |
| 永久外国人现象 | 居住数代仍被追问"你到底哪里来的"，影响归属感与对外代表角色的分配 | 不是好奇心问题，是归属与代表性的问题 |
| 文化流畅性 | 按场合开关或调节自身行为面向的能力，核心是"不必变成另一个人" | 常被误读为同化 |
| 同化 / 濡化 | 同化＝以自身文化特征为代价采纳主流；濡化＝采纳主流运作模式同时保留本族价值 | 日常混用为"融入" |
| 动机技能 | 从你愿意反复做、能讲出细节的故事里提炼出的技能 | 差别在**来源**：故事证据，而不是自评形容词 |
| 上升信号 | 以可观察信号判定流动性：是否代表公司露面、是否入专项组、高层是否征求你意见、是否提前得知未来计划 | 不是主观"觉得停滞" |
| 耻感文化机制 | 失败被视为公开羞耻 → 回避冒险与暴露不完美 → 回避高可见度任务 | 不是"爱面子"的性格描述，而是一条成因链 |
| 同质再生产 | 管理者倾向提拔与自己相似的人，使领导层结构自我复制 | 不是"喜欢相似的人"，而是选拔环节的结构性偏差 |
| 继任管道 | 组织为关键岗位储备接班人的流程；不在名单内，绩效再好也无法兑换关键岗位 | 把晋升重述为流程内/外的二元位置 |
| 友好雇主 | 可由可观察实务判定的雇主类型，并配套面试与网络场合的提问清单 | 不是"氛围好"，而是证据加提问清单 |
| 双文化状态 | 在家一套规范、在外另一套的长期切换，并延续到职场行为 | 不是"会两门语言" |
| 他人眼中的独特价值 | 别人最记得你什么、会用哪两个形容词描述你——由他人回答，不是自封 | 不是"核心竞争力"的自评版本 |
| 可见度 | 你的贡献被谁、在什么场合、以什么形式知道；等于信息分发结果 | 不是"爱出风头"的道德问题 |
| 跟进（追进） | 诉求提出后的主动追问与再确认；无跟进的诉求视为已撤回 | 日常当作"催促" |

## 使用提示

- 这些词**不是普适概念**：迁移到其他职场语境时需要重新检验本包定义是否成立。
- 族裔相关术语（bamboo ceiling / 模范少数族裔 / 永久外国人 / 象征性代表）描述的是特定职场
  环境中的机制，**不得用于预测或评判具体个人**。
- 与卡内表述冲突时以能力卡为准，本表只负责统一定义，不引入卡外新概念。
