# 决策规则速查

| 能力 | 一句话规则 |
|---|---|
| 会前预连线与异议表达 | 反对意见要活下来，靠的是会前 1–2 天的知情权前置，而不是会场上的勇气。 |
| 会议发言争取 | 发言位次本身就是信号：争取前三位开口，会前准备好一个发言点和一个问题。 |
| 向上沟通：澄清、改判与说不 | 把分歧从'不孝'重新归类为技术性讨论：提问澄清、1v1 改判、承诺必须带跟进日期。 |
| 非语言可信度（眼神与录像反馈） | 尊重被解码成心虚：用录像拿到自己信号的外部读数，重点守住被追问时的视线。 |
| 双刃行为转换器 | 同一种行为既有代价也有资产：保留资产，只改可见形式，禁止全盘改人格或全盘无视误读。 |
| 成果归档（职责清单+成就档案+自评） | 绩效体系是记录系统：书面职责、同一张目标清单、随身成就档案，缺一都会被事后重写标准。 |
| 绩效谈话与全年反馈闭环 | 反馈的时间单位是项目不是年；薪酬诉求永远排在绩效对话之后。 |
| 薪酬与晋升谈判准备 | 进场前必须有区间、愿望清单、下限三个数；base 不可谈时把钱拆成组件去换。 |
| 引导者四型地图 | 导师要按功能分散：能在候选名单讨论里说出你具体工作的那个人，才是你不能缺的 sponsor。 |
| 天花板与流动性诊断 | 上升与否看外部信号而非感受：代表公司露面、入专项组、被高层征求意见、提前知道未来计划。 |
| 新岗位基础设施搭建 | 入职头 90 天自建三样：一个能答小事的 buddy、一张组织图、每人 15 分钟的接口遍历。 |
| 外部反馈征集 | 别猜别人怎么看你：向高一两级、既懂你工作又懂你的人索取四维度反馈，并且必须面谈收尾。 |
| 岗位定位 | 目标必须同时含职能与行业，且在写 pitch 之前确定；不知道岗位真实内容就去问，不要猜。 |
| 个人说辞三约束 | 30–45 秒讲清'我是做什么的 + 我现在想要什么'；绝不在信息访谈里索要推荐。 |
| 面试成就叙述重写 | 同一件事讲得不像做过：补齐'我的动作+我的判断+结果与代价免除'，团队仍在场但你不能缺席。 |
| 面试演练闭环 | 没有第三方反馈的练习是把错误练熟；一次只改一项，且触达要礼貌地坚持到上限即止。 |
| 人脉分层与长期维护 | 任意时刻要有 5 个能说出你工作事例的人；访谈里推进对话是你的责任，不是对方的。 |
| 雇主适配尽调 | 看公司派谁去代表它，就知道它看重谁；提问要像好奇，不像审计。 |

> 速查只给结论；需要依据、案例或反例时读对应能力卡。
