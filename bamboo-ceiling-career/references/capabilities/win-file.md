# 成果归档（职责清单 + 成就档案 + 自评）

## R｜规则要点

前提：**绩效体系是记录系统，而记录系统会流转**——转岗时既有评估会随档送到新部门，
评估同时用于区分绩效相近者与支撑激励决策。由此推出三条文书规则：
尽早索取书面岗位职责；让上级写明**本评估周期要完成什么**，此后所有绩效讨论都回到
**同一张清单**逐项对照；平时积累**成果档案**（你特别引以为傲的成果记录），讨论时随身带。

## I｜这条能力在说什么

前提是：**绩效体系是记录系统，而记录系统会流转**。具体机制——在某些公司，
员工申请转岗时，前两次绩效评估会被送到新部门审阅；评估同时是区分绩效相近者的依据，
也是奖金与调薪的正当性来源。

因此三条规则不是"要自信"，而是文书规则：

1. 尽早索取书面岗位职责；拿不到就和上级当面把主要职责写下来。
2. 让上级写明**本评估周期要完成什么**，此后所有绩效讨论都回到**同一张清单**逐项对照。
3. 平时积累成果档案——你特别引以为傲的成果记录，讨论时随身带。

"同一张清单"这条最容易被忽视，也最有用：目标漂移只有对照旧文本才可见，
否则年终时你面对的是一份被事后重写的标准。

## A1｜案例（已脱敏）

- 明确写出评估的多重用途：记录你的绩效、区分绩效相近者、支撑激励决策；
  并以"转岗时前两次评估随档送审"说明记录的外部流通性。
- 要求"如果全年没有持续对话，就要额外仔细准备：写下本年度主要成果 + 诚实的自评
  （优势与待改进），并带上成就档案"。
- 年度评估同时被定位为发展规划的场合，而非首次听坏消息的场合。

## A2｜我的适用表述

三件工件，缺一不可：**书面职责**（标准是什么）、**同一张目标清单**（本季承诺了什么）、
**成就档案**（实际发生了什么、证据在哪）。

它的收益是防两类具体损失：目标被事后改写；以及你确实做了但没人记得的事在评估里不存在。
与相邻能力的区分：`performance-discussion` 管**对话**（怎么谈、什么时候谈）；
本卡管**弹药**（谈的时候桌上有什么）。`external-feedback-probe` 提供第三方视角的证据来源。

## E｜执行

**输入**：现有岗位说明（或空缺）、本周期目标、日常产出与反馈记录。

**步骤**

1. 索取或共创书面职责：一页以内，主要职责条目化。拿不到书面的，用邮件把口头约定复述给对方确认。
2. 建立目标清单：本周期要完成什么 + 每条的可验证判据。日期与版本要留痕。
3. 建成就档案：每条一行，字段固定——时间 / 项目 / 我的动作 / 结果（尽量量化）/ 证据所在位置 /
  涉及的人。原则是**当场写**，不要靠年底回忆。
4. 日常反馈入库：来自上级、同事、客户、下属的正负反馈都归档（负面更要留，它决定你要补什么）。
5. 自评用同一张目标清单逐项写：完成 / 部分完成 / 未完成 + 原因。禁止换一套新指标。
6. 会前把三件工件合并成一页摘要，会上按清单顺序讲。

**输出**：书面职责、版本化目标清单、成就档案（含证据）、自评稿。

**完成标准**：评估会上你的每一项主张都能指向档案里的一条记录；
没有出现"这个我不记得/这是什么时候的事"。

## B｜边界与不适用

- **不做**：把成果档案变成美化材料。自评应包含待改进项；只记好消息的档案在评估中反而降低可信度。
- **合规与隐私**：档案里不要放客户名称、薪酬数字、内部数据或同事的可归因评价；
  证据用"内部系统链接 + 编号"而非整段粘贴。
- **组织假设**：本能力集假定存在书面评估体系。若公司完全没有正式体系，本卡的替代是：
  自己维护同一张清单并按季度主动发起 15 分钟对照谈话（此替代为本卡推断）。
- **文化风险**：把成果写成"我的动作"在部分团队会被读成抢功。可与 `behavior-reframe` 并用：
  团队在前、个人那一步在后，但**那一步必须在**。
- **时代限制**：口径形成时以邮件与纸质档案为主；今天证据多分布在 IM、代码仓库、工单系统，
  需要解决"链接失效"与"跨系统归档"这两个本能力集未遇到的问题。
