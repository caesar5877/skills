# 外部反馈征集（可信顾问式）

## R｜规则要点

一份**可信顾问反馈征集**流程：征集对象怎么选（公司内一到两位、比你高一到两级、
既了解你的工作又相对了解你，并纳入理解你的文化如何影响你行为的人）、
可直接使用的征集信函、四个反馈维度（技术与系统能力／人际能力／发展领域／
他人眼中的独特价值）、保密与坦诚的承诺，以及"回收后必须面谈收尾"的要求。
它与绩效谈话、教练复盘构成同一套外部读数系统。

## I｜这条能力在说什么

这是本能力集里唯一给出**可直接使用的征集信函**的工具，也是把"别人怎么看我"从猜测变成数据的唯一路径。

操作要点有四：

1. **选谁**：本公司一到两位、比你高一到两级、既了解你的工作又相对了解你本人的人；
  他们也可以同时是导师。另外建议纳入**理解你的文化如何影响你行为的人**
  （父母、朋友、亲属、亚裔导师）——这是一条少见的、针对文化误读源的取样设计。
2. **说清目的**：信函里要在四个目的中选一个明写（识别作为管理者的强弱项 / 了解密切合眼中的自己 /
  判断什么职业适合自己的技能性格经历 / 为现职制定可执行的发展计划）。
  目的不写明，反馈就会变成安慰。
3. **保证保密并请求坦诚**："请在你感到舒适的范围内尽量坦率"，并承诺严格保密。
4. **必须面谈收尾**：回收后尽快与对方做一次面对面交流，这条是强要求而非可选项。
  书面反馈没有追问就无法变成行动。

同时必须承认：对亚裔美国人而言索取诚实反馈本身更难，但外部反馈是衡量自身表现的必要条件，不可省略。

## A1｜案例（已脱敏）

- 给出四个反馈维度：技术/产品/系统能力；人际能力（果断、表达、口头书面沟通、冲突管理、
  个人风格、灵活性、处理模糊性的能力）；发展领域（领导力、职能技能）；
  专长领域即"他人眼中的独特价值"——别人最记得你什么、你会用哪两个形容词描述我。
- 明确"总是直接获取反馈对各方最有利"，同时说明可通过第三方视角间接了解（两种路径都成立）。
- 另一位职场新人的日常版本：不等反馈，主动索取，改完立刻再实战。

## A2｜我的适用表述

产出是**一份已发出的征集 + 四个维度的回收记录 + 一次面谈 + 一项发展计划输入**。
它与其他卡的关系是供料：`mobility-audit` 的个人障碍栏、`behavior-reframe` 的"误读"列、
`nonverbal-credibility` 的评分人，都依赖这条能力产生的外部读数。

**他人眼中的独特价值这一维最容易被跳过，却最值钱**：如果你答不出"别人最记得我什么"，
`pitch-three-s` 与 `interview-narrative` 也写不出有辨识度的内容。

## E｜执行

**输入**：1–2 位公司内征集对象（高一到两级）、1 位理解你文化背景的对象、四个维度问题、可用面谈时间。

**步骤**

1. 选定对象并确定**唯一目的**（四选一）。目的多于一个会让对方不知如何取舍。
2. 发征集信息：一封 150–200 字的短信即可，五个要素缺一不可——
  ① 你在做什么（一次自己的发展盘点）；② 为什么找他（既了解你的工作、也了解你这个人）；
  ③ 四个维度各一句（技术与系统能力 / 人际能力 / 最该补的一项 / 别人眼中你最突出的价值）；
  ④ 保密承诺与需要的坦诚程度；⑤ 回收时间与一次 20–30 分钟面谈。
  可直接改写的模板："我在做一次自己的发展盘点，想请一两位我看重的人给我坦率的反馈。
  范围是过去 12 个月的工作：我技术上与系统上的强弱、我与别人协作时的表现、
  我最该补的一项，以及别人眼里我最突出的价值是什么。内容只用于我个人的发展计划，
  不会外传；越具体越好，能举近期的例子最好。方便的话我们约 20 分钟面谈。"
3. 回收后 48 小时内约一次 20–30 分钟面谈。面谈只问三类问题：
  举个最近的具体例子 / 这件事你当时怎么解读 / 如果只改一件事你会说哪件。
4. 把反馈按四维度归档，区分"事实（可指认事件）"与"印象（无事件支撑）"。印象类需要用
  `performance-discussion` 或更多来源验证后才进入行动。
5. 收敛为**一项**发展计划输入：各项结论最终要进入发展计划。选一项能改变他人读数的动作，
  写进下一次 `mobility-audit` 复测的观测项。
6. 回访致谢并告知你做了什么改变——这让下一次征集更容易（与 `network-long-game` 的互惠规则同源）。

**输出**：征集记录（对象/日期/目的）、四维度回收表（事实与印象分列）、面谈纪要、一项发展计划输入。

**完成标准**：至少 2 位对象回收并完成面谈；至少 1 条反馈能对应到具体事件；
产出 1 项可观测的发展动作。

## B｜边界与不适用

- **不用于替代正式评估**：这是自助诊断工具，不能替代公司绩效流程，也不要把未验证的印象写进自评。
- **权力风险**：向直接下属索取反馈时，坦诚度会被权力压制；这里的取样是"高一到两级"，
  反向取样需谨慎解读（本限制为本卡推断）。
- **隐私与安全**：征集中不要索取或记录健康、家庭、性取向、宗教等与绩效无关的信息；
  文化背景类问题只问"行为如何被解读"，不问身份本身。
- **缺口**：未给"多位反馈互相矛盾"的处理方式；常见解释是场合差异或对象立场不同，
  需按事实/印象分列后再逐条验证。
- **时代限制**：基线的场景是纸质/邮件量表加面谈。今天可通过表单工具匿名收集，
  但匿名会削弱"直接获取反馈最有利"的前提——本卡默认实名 + 保密承诺。
- **未证部分**：未讨论"征集来的反馈本身就是偏见"这一可能，只假定反馈更接近真实。
