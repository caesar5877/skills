# 非语言可信度（眼神接触与录像反馈）

## R｜来源与依据

原书印刷页 p.42–43（面试中的非语言线索）、p.154–155（Misunderstood Nonverbal Cues，Michael Lee 个案）。

## I｜这条能力在说什么

作者指出两组常被误读的信号：眼神接触不足与握手过轻。机制是文化翻译错误——
在许多亚洲情境里，与权威长时间对视是不敬；被教养要对父母、老师少对视的人，
进入面试场景会自动复用同一套动作。而招聘方把同一动作解码为：不自信、不感兴趣、答案不确定，
甚至"看似不诚实"。

Michael Lee 的自我诊断极其精准：他意识到自己在**面试这种层级结构**里会自动移开目光，
因为"要对在场掌权者表示尊敬"。这不是习惯，是情境触发的。

能力核心因此不是"多看着人"，而是三件事：① 用录像或第三方评分获得自己信号的**外部读数**
（自己感觉不到自己在回避）；② 按场景分别设目标，而不是全局提高强度；
③ 重点守住难题时刻——被追问时移开视线，是可信度损失最大的一刻。

## A1｜原书案例（非合成）

- Michael Lee：韩裔、10 岁来美、英语流利，求职零售买手半年无果。模拟面试**录像回放**后他自己
  说出触发结构（层级场景→自动低头致意）。经针对性练习（从数秒开始逐步延长），两个月内拿到 offer。（p.154–155）
- p.154 招聘方原话方向：一位日裔女性履历与资质都强，但在被问难题时移开视线，
  "随着她视线降低，几乎显得 deceitful"；她改善非语言信号后面试表现明显提升。
- p.42–43 明确写：因为可能被完全误读，所以要做模拟面试并请同侪诚实评估你的眼神接触量。

## A2｜我的适用表述

把自己的非语言信号当作**外部系统读数**问题：意图正确不等于信号正确，唯一有效的检验是回看录像。
可执行判据：① 有一次带录像的模拟；② 标出移开视线的触发问题类型；③ 在压力问题上守住视线。

与相邻能力的区分：`interview-narrative` 管内容怎么讲；本卡管讲的时候观众收到什么。
`behavior-reframe` 是上位映射表，本卡是其中一个已被完整验证的行。

## E｜执行

**输入**：目标场景（面试 / 汇报 / 评审）、可给你评分的人、录像设备（手机即可）。

**步骤**

1. 录一次 20 分钟模拟问答，包含 3 个让你不舒服的追问。
2. 回看，只做一件事：标记移开视线的时刻，并写下当时的问题类型（追问 / 数字 / 冲突 / 自我评价）。
3. 与评分人约定三个可观察指标：眼神落在对方脸上约多少比例、思考时是否仍面向对方、
   被打断时是否转向对方。阈值自定并记录（原书未给标准）。
4. 分级练习：先在被追问时延长注视到数秒，再到完整回答期间保持；每次只练一项。
5. 复测：再录一次，与首次逐指标对照。

**输出**：触发点清单 + 指标基线与复测值 + 场景化目标（面试 / 汇报各一条）。

**完成标准**：在追问类问题上不再出现向下移开视线；评分人在盲评中能指出"更稳了"。

## B｜边界与不适用

- **不覆盖非文化成因**：若视线回避与自闭谱系、社交焦虑症、创伤反应等相关，本卡的"练就行"框架不适用，
  应优先专业支持而非自我训练。原书完全未处理此情形。
- **不做**：把"眼神接触多"当成普适美德。跨文化、跨个体差异都很大，且过度凝视会被判为侵略；
  作者本人也强调"不是盯视"。
- **风险**：只改信号不改实质，会短期提升印象、长期损害信任。本卡必须与内容类能力配套使用。
- **时代限制**：视频面试中"眼神接触"的技术定义不同——要看摄像头而非对方眼睛，
  且画面缩小会放大凝视感。原书场景是面对面，需按镜头重新校准。
- **未证部分**：Michael Lee 两个月拿到 offer 为个案，无法分离"眼神改善"与其他变量的贡献。
