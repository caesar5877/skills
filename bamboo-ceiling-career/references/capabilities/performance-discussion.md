# 绩效谈话与全年反馈闭环

## R｜规则要点

绩效讨论的四条规则：**年度评估不是第一次听到"你去年哪里该改"的场合**；
反馈的正确时间单位是项目与会议，不是年；薪酬诉求永远排在绩效讨论之后；
谈话要按你自己的议程把所有要点谈完，并把结果用于发展规划而不只是核对过去。
配套一条组织事实：评估记录会随转岗流动，也会成为激励决策的依据。

## I｜这条能力在说什么

核心断言是一句时间规则：**年度评估不是第一次听到"你去年哪里该改"的场合**。
反馈的正确时间单位是项目和会议，不是年。节奏很具体——
完成一笔交易、拿下一个客户、结掉一个项目阶段之后，就该去要反馈。

第二层是**顺序规则**：薪酬诉求永远挂在绩效讨论之后。
本卡把"毫无依据走进办公室要加薪"直接称为低效行为；要求是把"表现怎么样"先谈清楚，
再谈钱，且谈话中要"主导谈话节奏"，把所有你想谈的点谈完。

第三层是案例里的操作细节：一位新分析师不等待反馈，每次客户汇报后立刻向资深银行家索取，
听到直接甚至严厉的批评后立刻改法、再上、再要反馈，连续三个月。
特别记下另一半原因——那位资深银行家把所有不受限的客户会议都带上这位新人，
因为"给 junior 曝光"不是所有人的默认动作。也就是说：**反馈与曝光都需要你去要，两样都不会自己来。**

## A1｜案例（已脱敏）

- 一位新分析师与一位资深银行家：三周内完成"要反馈 → 改 → 再实战 → 再要反馈"的多轮循环；
  这种非正式的实时反馈是"最有价值的部分之一"，并知道资深银行家主动带新人见客户并非行业常态。
- 一位提薪酬诉求的员工：反面。提出薪酬问题后被"我查一下"打发，选择不追，再无下文。
- 四条小结明确写出：定期索取反馈；要加薪前先发起绩效讨论；
  谈判要懂薪酬与绩效管理的语言；语气坚定但讲理。

## A2｜我的适用表述

两个可检查节拍：**每个重要交付后一次反馈索取**，**每次薪酬动作前一次绩效对话**。
它对抗的是两个系统性错误：把反馈当成上级主动给予的礼物；把薪酬谈判当成独立事件。

与相邻能力的区分：`win-file` 负责证据；本卡负责对话设计与时机；`comp-negotiation` 负责钱的具体谈法。

## E｜执行

**输入**：本周期目标与职责清单（来自 `win-file`）、当前反馈记录、最近的重要交付。

**步骤**

1. 设定反馈触发点：把"交付客户报告 / 上线 / 结项 / 重要会议"写进日历，每个触发点跟一条索取动作。
2. 索取要具体且可执行：不问"我表现得怎么样"，问"这次汇报里，如果只能改一件事让结论更有说服力，改哪件"。
3. 收到负面反馈时，当次对话结束前确认三件事：问题、改进动作、验证时机。强调这位新人的关键是**立刻再实战**。
4. 年度会前准备：按目标清单写自评（含待改进），带上成就档案摘要，并准备发展规划议题
  （下一步是什么 / 想要什么 stretch 机会）。这场会应当主要用于发展规划。
5. 若全年几乎没有反馈对话：视准备为**额外功课**而非运气问题，把准备做厚（的额外准备要求），
  并在当年把"定期反馈"作为明确诉求提出。
6. 薪酬动作前：先安排绩效讨论并取得结果，再进入 `comp-negotiation`；两次对话不得合并成一次。

**输出**：反馈触发点表、每条反馈的"问题/动作/验证时机"三行记录、自评稿、发展规划议题清单。

**完成标准**：年度评估前已有 ≥3 次可记录的反馈对话；薪酬诉求出现在绩效对话之后；
评估会上没有出现首次听到的负面评价。

## B｜边界与不适用

- **不覆盖**：没有绩效体系、或绩效体系与晋升无关的组织。此时本卡的价值转为个人节奏管理，
  但不要期待它能改变晋升结果（结构问题交给 `mobility-audit` 判定）。
- **不做**：把反馈索取变成反复求确认。姿态标准是"追求卓越的坚持"，不是"需要被安抚"。
  同一议题短期内多次索取评价会消耗对方耐心。
- **权力不对称**：若索取反馈换来的是贬低或报复，这是环境问题而非技巧问题；停止优化话术。
- **时代限制**：本能力集场景为面对面、以邮件为主的办公环境。今天大量反馈发生在异步 IM 与文档评论里，
  需要主动把散落的评价**收集归档**，否则所强调的"记录"无从建立。
- **未证部分**：未量化"更多反馈"与"更好评价"之间的关系。
