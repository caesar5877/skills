# 能力集概览（overview）

> 本文件回答**非能力类**问题：这套能力覆盖什么、不覆盖什么、各能力之间怎么衔接、
> 使用时该注意什么。回答这类问题时不要加载能力卡。
> 本能力集完全自包含：所有清单、脚本、判据与阈值都写在包内，离线可用，
> 不需要查阅任何外部资料、量表或链接。

## 一句话主旨

亚裔——以及任何文化背景与主流职场规范不一致的从业者——在美国大公司的入门岗位与学历指标上
超前、在高管层严重缺席；原因不只是外部歧视，还包括文化养成（谦逊、避冲突、敬权威、
"把活干好自然被看见"）与西方公司对可见度、自我推销、关系经营、当面表达的隐性要求相冲突。
破局要同时做两件事：管理自己的文化惯性，并按这套规则主动经营可见度、关系与谈判。

## 主题骨架

1. **诊断**：用数据打破"模范少数族裔"神话；身份认同塑造了被误读的职业形象。
2. **机制**：一整套双刃文化习惯在评估、面试、会议与社交场合被读成"缺领导力"。
3. **环境**：公司多元化实务的成熟度决定同样行为的代价，选雇主是可操作变量。
4. **自我评估**：把"我是什么样 / 别人怎么看我 / 我要去哪"变成有记录的诊断。
5. **入口战术**：面试表达、个人说辞、人脉。
6. **在职战术**：流动信号、引导关系、自我宣扬、说"不"、新岗位基础设施、绩效与谈判。
7. **收束**：一切回到"可见度 + 证据 + 跟进"。

## 核心命题（归纳）

1. 入门与学历超前而高管缺席，说明阻碍不是"不够努力"。
2. 绩效评分不是勤奋与工作量的函数，它同时包含协作、沟通与被谁谈论。
3. 文化习惯是双刃：同一些品质既是资产，又在特定场合被误读。
4. 沉默被当作内容：不发言被读成没想法、傲慢或没兴趣。
5. 破局要求"改行为但不换人格"——按场合调档，不要求长期违背自己。
6. 外部反馈是必需品：可信顾问评估、绩效谈话、教练复盘构成同一套读数系统。
7. 关系是信息基础设施，回避等于自我信息隔离。
8. 引导者要分层获取：sponsor 决定机会集合，mentor 教，同行搭子给雷区图，榜样角色给可见性。
9. 风险回避被耻感放大，而高可见度任务必然带风险。
10. 谈钱与谈晋升是同一项技能，需要数据、流程知识与跟进。

## 能力之间怎么连（包内链接）

- `mobility-audit` 给出"内部投入 / 外部行动"的分支；外部分支由 `role-targeting`、
  `employer-fit-probe` 接手，内部分支回到 `performance-discussion` 与 `guide-map`。
- `win-file` 提供证据底座，`performance-discussion` 决定何时开口，`comp-negotiation` 决定怎么谈。
  顺序不可颠倒。
- `prewire-disagreement`、`upward-dialogue`、`meeting-voice` 共用同一张"场合 × 时点"判定：
  内容相同，提出场合与顺序不同，被读出的含义就不同。
- `external-feedback-probe` 与 `nonverbal-credibility` 提供外部读数，
  `behavior-reframe` 与 `mobility-audit` 消费这些读数。
- `pitch-three-s`、`interview-narrative`、`interview-rehearsal` 共用同一批素材：
  成果档案里的条目就是 pitch、面试答案与跟进说辞的原料。

## 批判与限制（各卡 B 段的汇总）

- **时代**：判据形成于约二十年前的美国大公司场景——面对面会议、纸质与邮件档案、
  线下引荐、电话跟进。当代渠道与制度（IM 与文档评论、远程与混合办公、视频与录像面试、
  简历自动筛选、薪酬透明立法、线上社群）本能力集**没有覆盖**，各卡 B 段逐条标注了缺口。
- **立场偏向**：视角偏向招聘方与个人可操作层面，天然倾向"改变可观察行为即可改善处境"；
  默认舞台是西方大公司管理层。它会把结构性问题翻译成个人任务，这是这套方法最大的弱点。
- **未证明假设**：行为修正 → 评价提升 → 晋升的效应量从未被测量；假设评估者会更新判断且
  不记仇；假设个人有条件获取外部反馈、录像回放与模拟演练的机会。
- **最强反驳**：把权力与评价标准的分配问题译成个人技能清单，等于要求被评价不利的一方承担
  文化翻译劳动，并反向印证主流标准的中立性。因此本能力集的定位是**信息不对称的补偿工具**，
  不是"照做即晋升"的承诺。
- **族群框架的两面**：以族裔为分析单位自带刻板化风险。本包把它当作"被误读风险的场景描述"
  使用；任何群体概括都不得用于预测或评判具体个人，先验证机制是否落在自己身上再行动。

## 不覆盖（明确声明）

- 薪酬数字、市场区间与报价——包内不含任何定价数据，也不提供估算方法之外的数字。
- 劳动法、仲裁、遣散与竞业条款的法律解释（方法基于美国雇佣语境，不构成法律意见）。
- 临床心理议题：社交焦虑症、惊恐、抑郁、自闭谱系。出现这些信号应停止使用本能力集。
- 家庭与亲属关系的深度协商（只有个案叙述，无可复用流程）。
- 管理者视角的团队管理动作（本包视角始终是被管理者/求职者）。
- 需要当期统计或政策依据的问题（时效基线约二十年前，且不随包更新）。

## 使用与时效声明

- 十八张能力卡统一为 R（规则要点）/ I（解释）/ A1（案例）/ A2（应用）/ E（执行）/ B（边界）六段；
  每张卡自带清单、脚本与阈值，**照卡执行即可，无需外部资料**。
- 卡内标注"本卡推断"的判据是使用者约定，不是既定结论；首次使用时把阈值显式写下来。
- A1 段案例已做脱敏处理，只保留机制；不要把它们当作统计证据或真实人物。
- 本包不随时间更新数据。凡涉及当期市场、法律或政策，一律先声明超出时效，不做推断性回答。
