# 记忆方法工作坊 — 能力入口

## 触发与不触发

**适用**：与本书能力域相关的咨询与任务（见下方路由表的意图列）。
**不适用**：
- 提供原书码表、字母表、牌码、二进制表、元素含量、税率等“取值”本身（扫描版 OCR 表格受损，且部分属外部事实/时效资料）
- 需要理解与运用的知识教学（作者自设边界：纯记忆知识点一般 ≤30%，单词约 70% 适用）
- 病理性记忆问题、神经认知障碍的评估或干预；学习焦虑的心理治疗
- 儿童英语发音训练中的谐音替代（发音定型期人群风险，作者本人设限）
- 承诺“永久记忆”“一字不漏”或替代考试与专业判断
- 用药、保健品与“补脑”类建议，以及记忆力减退的病因判断（阶段 4 诱饵实测后补入： 原文本对此无条款，而这类请求需要一个可依据的拒答理由）
- 职业选择与行业收入判断（阶段 4 诱饵实测后补入：作者成绩属自述、无第三方记录， 不能当行业可行性依据）

## 核心原则（常驻速览，概览类问题读到这里即可回答）

1. 记不住通常是“关联缺失”而不是脑子笨：把新信息挂到已经熟悉、可复现的载体（码、桩、题干）上，才有提取线索。
2. 效果优先于道理：联想是否优雅、是否“科学”都不重要，唯一检验是需要时能否准确回忆出正确信息。
3. 载体决定上限：串连不保序、身体桩容量小、随机指定的载体本身成为新负担——长期材料必须独占稳定载体。
4. 画面必须发生在地点上，且具体到颜色形状边角；否则线索存在却无法触发回忆。
5. 记忆是闭环：通读简化→选择方法→奇像记忆→科学复习，缺一步就不得宣称“记住了”。
6. 造出来的关联同样难以撤销：先确认答案正确再编逻辑，否则会固化错误。
7. 方法不等于能力：每种手法都要练到不费力的量化门槛，训练量不足时任何配方都不成立。

## 边界与判停

- 材料属于理解型/推导型 → 不使用记忆法硬套，先解决理解，只把其中纯记忆条目交给本包
- 用户要的是具体数值或现行规范 → 明确拒答并指向权威来源，不用本书数值替代
- 使用者是发音未定型的儿童且方案依赖谐音 → 停止该方案，改用非谐音路径或声明风险
- 载体尚未记熟（码表/桩组不能默背或自动反应） → 先补基建，不进入记忆任务
- 出现“编造的逻辑指向错误答案” → 立即停用该联想并用新逻辑覆盖，不得靠提醒纠正
- 归因先于重选（阶段 4 新增的包内规则，非原书文字）：用户在问“是方法不对还是我没做对”时，先做四维归因（self-check）， 再决定换方法、换载体还是加训练；不得一上来就让用户重建载体
