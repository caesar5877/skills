# 决策规则速查 — “记忆达人教你神奇记忆术”

| 能力 | 一句话规则 |
|---|---|
| 记忆任务诊断与方法选路 | “先看要存多久、要不要保序、要不要随机提取：短小琐碎串连，有序条款用数字码，海量随机用地点桩，题干可拆用标题定位；需要理解的不交给记忆法。” |
| 记忆宫殿（地点桩）建造与体检 ★用户重点 | “桩组要过四关才算建成：熟悉、单向有序、每个桩有可区分特征、数量取整，且能闭眼按序默背。” |
| 画面放置与联想质量校验（含排障）★用户重点 | “回忆不出东西时先判类型：动作没落在地点上、图像不具体、桩同质错序、载体不独占、画面与目标词关系太松——每种都有对应改写。” |
| 海量任务的载体映射（任务降维）★用户重点 | “先找任务自带的有序编号（箱号、座位号、方阵号）当载体，再把非数字信息转成可记单位，剩余待记量就能算出来。” |
| 00–99 数字编码库建立与校验 | “编码库要一物一码、能自动反应；先做唯一性冲突检查，再用随机抽测计时验收，否则不许上任务。” |
| 复习排程（六次间隔 + 抢救窗口 + 回忆式复习） | “记完 10 分钟到 1 小时内先做一次抢救性回忆，之后按 1 天/1 周/1 个月/6 个月/1 年推进；每次用回忆而不是重读，模糊就插队。” |
| 长文背诵六步（含四种载体选路与还原修正） | “背长文不是重复：通读→按材料性质选载体→提‘关键意思’而非关键词→忆→还原修饰词→定时复习，回忆出八九成即合格。” |
| 有序条款与问答题的数字定位（含载体独占） | “条目按序编号→取对应码→码与每条大意造一个动作→按号点背；长期备考的题必须独占一段码，不共用载体。” |
| 标题定位（题干即索引） | “答案条数少时，从题干取等量且有意义的字当桩，看题即出答案；取不出有意义单位就退回数字定位。” |
| 抽象材料转换手法与择优（含造逻辑安全门） | “抽象词先变具象：谐音、加减字、倒字、替换、望文生义取其一，选哪种取决于后面要跟它关联的对象；编逻辑前必须先确认答案正确。” |
| 记忆四步总流程（编排卡） | “一次完整记忆 = 通读简化（只留 10%–20%）→选方法→奇像记忆→复习；四步不齐就不能说记住了。” |
| 单词记忆方法选择器 | “看词形派方法：熟词/形似熟词、拼音、谐音、词素、部分提取；联想牵强就退回传统方法，约三成的词本就不适合。” |
| 单词复习管理系统（三三原则 + 计数升级） | “一天三时段、每时段同组记三遍、第四次改看义拼写；失败两次升级红圈进页眉，页脚‘正’字计数决定当天优先级。” |
| 年代与数据配对（谐音 / 编码 / 推算三径） | “年代能自然谐音就用谐音，否则一律转数字编码联结；成组年代先找等距、起讫、逐年关系建推算链，少记绝对数。” |
| 清单压缩：字头歌诀与配对锁定 | “无逻辑清单取字头谐音成一句人话，再靠‘由句还原全部条目、不多不少’验收；配对类拆限定词+专名，并显式排除易混项。” |
| 数字与扑克训练计划（读码门槛 + 里程碑） | “读码不达标不许上任务：扑克 52 张读牌 ≤1 分钟、备齐 26 桩×≥10 组才开记；每天早晚各 1 小时，先求清晰再求快。” |
| 思维导图绘制与四场景应用 | “导图不是画画：中心图+一线一词+词在线上+分支只从节点分出+轮廓近圆；复习时先闭卷画，再用异色笔补漏。” |
| 记忆品质四维自评与瓶颈定位 | “先分维度再动手：记得慢（敏捷）、忘得快（持久）、记错（正确）、提不出（备用）——备用性差要查检索线索而不是逼自己多背。” |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
