# GLOSSARY — 《记忆达人教你神奇记忆术》术语词典

> 阶段 3 产出，由 `candidates/glossary.md`（27 条，脚本预筛 + 回原文取定义）整理提升。
> 编译分发副本：`.cangjie/capabilities/book/glossary.md`。
> **页码一律为 PDF 页码 P0NN**（印刷页 ≈ PDF − 19）。频次为 `scratch/terms.py` 的全书计数，供判断术语重要性用，不代表正确性。
> 本词典只记**作者的用法**，不记词典义；与常识不一致处已单列，避免误用。

## 使用本词典的三条硬规则

1. **不要生造“联想法”一词**——全书出现 0 次；作者用的是 *联想 / 逻辑联想 / 奇像记忆 / 串连法*。
2. **“记忆馆 / 大小字母桩”是明确缺口**（仅 P144 一次、无定义）：不得据常识补建成方法，
   详见 `needs-review.md` NR-01。
3. **“记块 / 感块 / 原块 / 忆块”是作者自造模型**（仅 P013 一节、无出处）：可当解释话术，
   **不可当科学事实**引用（`references.md` r01/r09）。

## B. 载体与编码

| 术语 | 作者的用法 | 与常识的差异 | 首现 / 频次 | 相关能力 |
|---|---|---|---|---|
| 定位法 | 用“熟悉、已记熟、有固定顺序”的载体按序承载信息的总称（身体 / 数字 / 地点 / 标题四种变体） | 不是“确定位置”，而是“挂到预定索引上” | P040 / 48 | method-routing, palace-building |
| 宫殿记忆法 / 记忆宫殿 | 源自古罗马的记法；作者认为“门窗只是载体”，把它一般化为定位法 | 流行语境把它神秘化；作者降格为“熟悉载体 + 想象”，并否认与右脑开发有关 | P040 / 8 | palace-building |
| 地点桩 / 桩 | 充当索引的具体物件，须满足熟悉、有顺序、有特征；一组取整数（10/15/20），每桩默认 2 项 | 常识“随便找地方”；作者给选点与数量规范 | P047 / 13 | palace-building |
| 身体定位法 | 头到脚 10 个部位当有序载体；作者限定为临时记忆 | 别的书列为通用法；作者判它容量不足 | P043 / 4 | method-routing, palace-building |
| 数字（编码）定位法 | 把空间载体换成数字：序号为索引、码为图像，承载有序条款 | 重点在“有序槽位”，不是把数字画得形象 | P043 / 11 | clause-loci, number-code |
| 编码 / 数字编码 / 码（表） | 为数字或字母预绑定的固定图像；一次建库长期复用；须“滚瓜烂熟”且一物一码 | 不是临时发挥的“数字形象化” | P044 / 111 | number-code |
| 记忆馆 / 字母桩 | 单词工具清单里要求“牢记住记忆馆的大小字母桩” | **全书仅此一次、无定义**——缺口，不得据此编方法 | P144 / 各 1 | word-review-system（仅列为可选工具） |

## 码表骨架（结构可用，逐格值待核 — 对应 `references.md` r04）

> **为什么只有骨架**：原书附录“数字编码表”（P235–P238）与字母编码表（P157–P160）在扫描版里是表格图，
> OCR 出现错行与断行（NR-02 / NR-03）。因此本包**不复制成表、不代填充值**，只交付结构与建库规则；
> 作者本人也鼓励“可根据编码原则编造自己熟悉的编码”（P157）。

### 1. 数字码表（00–99）的结构

- **覆盖**：0–9 单码（是否单列须自行确认）+ 00–09（含零与重复数字）+ 10–99，共 100 格。
- **取码来源三类**：`形象`（数字本身像什么）/ `谐音`（读音像什么词）/ `意义`（专属联想物，如生日、门牌）。
- **唯一性约束**：一码一物、一物一码（P157）；两类冲突须清除——同图多名、同类不可分。
- **熟练门槛**：提前记到“滚瓜烂熟”，能自动反应（扑克路线的等价门槛是 52 张读牌 ≤1 分钟，P070）。
- **建库与验收方法**见能力卡 `number-code`（含冲突清单与随机抽测计时）。

**正文中可直接确证的取值（仅散见的 7 处，附录表不可用）**

|---|---|---|
| 1 | 蜡烛 | P044–P045（三十六计）、P121 |
| 2 | **鹅 / 鸭子（两处不一致）** | g04 词条作“鹅”；P096《沁园春·雪》例、P121 例作“鸭子” |
| 3 | 耳朵 | P044 附近、P121 |
| 10 | 棒球 | P045 |

> 直接照抄任何一份“完整码表”都可能与例题冲突——本包的立场是**用户自建 + 唯一性校验**。

### 2. 字母编码（P157–P160，不可整体引用）

- **五类来源**：谐音化 / 拼音化 / 形象化 / 数字化 / 单词化（规则可用）。
- **组合编码**同样受唯一性约束：`i` 用了“医、姨”，`y`、`e` 就不能再用（P157）。
- **可确证的个别例子**：`A` 像帽子（形象化）、`b` 像 6（数字化）。其余取值**标为待核**，
  需要时按用户的字母联想习惯自建（方法见 `word-method-select`）。

### 3. 扑克牌码（P068–P070，表不可用，规则可重建）

- 正文可确证的对应：黑桃 A = 11、红桃 A = 21、梅花 A = 31、方块 A = 41、黑桃 K = 71（P067–P070）。
- 由此可推出构码规则：**花色占十位（黑桃 1 / 红桃 2 / 梅花 3 / 方块 4），点数或人物占个位**；
  J/Q/K 取 5x/6x/7x 属**保守重构**（原表 OCR 缺行，NR-04），使用前须自行核对一遍。
