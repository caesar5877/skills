# 清单压缩：字头歌诀与配对锁定

## R｜来源与依据

原书 P126–P132（世界之最的逻辑串连、数据编码、地壳元素、八大行星、氨基酸字头歌诀）、
P134–P140（注会税法口诀成品库，仅取其手法）。

原文（P130–P132，字头歌诀）：

> “用字头歌诀法，提取每个信息的首字：甲缬赖异苯亮色苏。采用谐音编成这样的小故事：
> ①甲携来一两本亮色书。②假设来借一两本书。”

配对类的关键点拆分（P126–P128）：“这一条信息的关键点有两个地方：面积最大平原，不是高度最高，
也不是面积最大的高原，是面积最大的平原；亚马孙。”

## I｜这条能力在说什么

两种“没有内在逻辑”的材料，两套压缩法：

**A. 顺序类清单 → 字头歌诀。** 每项取首字（或代表字），按目标顺序谐音成一句像人话的话：
“甲缬赖异苯亮色苏”→“甲携来一两本亮色书”；地壳元素“养（氧）闺（硅）女（铝），贴（铁）给（钙）
那（钠）家（钾）美（镁）青（氢）”；行星、微量元素同理（“铁猛碰新木桶”）。
取两个备选版本，谁好背用谁的。还原时由句子→字头→条目。

**B. 配对类常识 → 两点锁定。** 把一条知识拆成**限定词**（最大/最高/最长 + 类别）与**专名**两个关键点，
对专名做谐音/形象化或借常识（太平洋的警察——管得宽；南极洲最难到达；欧洲≈凹；阿根廷→梅西→牛肉），
造一句只指向正确配对的话，并**显式排除易混项**（不是高原、不是海拔最高）。

两条都带同一个验收器：**还原测试**。由歌诀必须能还原出全部条目，不多不少；
由配对句必须只推出正确专名，推不出易混项。

## A1｜原书案例（作者例题，非本卡合成）

- **字头歌诀**：氨基酸“甲缬赖异苯亮色苏”→“甲携来一两本亮色书”/“假设来借一两本书”（P130–P132）。
- **顺序 + 数据**：地壳元素“养闺女儿，贴给那家美青”（氧硅铝铁钙钠钾镁氢）；
  八大行星、人体微量元素同类；数据类用数字谐音（赤道周长约 4 万 →“死完”；71% 海洋 →“起义”；
  96% →“旧炉”）（P129–P132）。
- **配对锁定**：世界之最 13 条，手法含专名谐音（欧洲≈凹）、歇后语（太平洋的警察——管得宽）、
  常识嫁接（阿根廷→梅西→牛肉），并对“最大/最高 + 平原/高原”做显式排除（P126–P128）。
- **成品库（仅取手法）**：注会/税法口诀 11 组，如消费税品目“三男三女去开车”
  （P134–P140）。**其中的具体税率、扣除比例、罚款倍数属时效资料，本包不采用**（r07）。

## A2｜我的适用表述

**用户处在这些情境**：

1. 一串彼此无关但顺序/组合固定要考的要点（检查项、流程步骤、分类清单）。
2. 常识类“之最/第一/最多”配对，选项总是相近项。
3. 教材里的数据类知识点（百分比、面积、含量、排名）。
4. 想要“一句顺口溜”而不是背十条。
5. 担心口诀背顺了却漏项、串项。

**语言信号**：“帮我编个口诀”“这些怎么串起来好记”“顺序不能乱”“世界之最记不住”
“这几个选项老混”“有没有顺口溜” / “make an acronym for this list”“mnemonic for these items”
"I always mix up the superlatives"。

**与相邻能力的区分**：

- `clause-loci` 保留每条的独立内容并支持按号点背；本卡把整组压成一个短结构，
  粒度更粗但更省力，需要“按号精确提取”时应转 clause-loci。
- `abstraction-conversion` 造单个词的转换；本卡管整组的压缩与配对锁定。
- `date-pairing` 是数字↔事件；本卡处理文字↔文字与顺序清单。
- `review-scheduler` 负责保持；口诀同样会忘。

## E｜执行

**输入契约**：① 清单原文（**顺序与内容必须已核实**）；② 类型判定所需信息：条目是否需要保序、
是否为“限定词 + 专名”配对；③ 考察形式（填空 / 点背 / 选择）；④ 条目数（>12 时须分组，见步骤 5）。

**步骤（A：顺序清单 → 歌诀）**

1. **取字头**：每项取首字或代表字；同字头冲突时改取第二字并在表中标明。
2. **谐音成句**：按顺序编成一句能读、有画面或有情节的话；产 **2 个备选版**。
3. **还原测试**：盖住原清单，由句子逐字还原条目。**判据：条目数正确、内容正确、无增无减**。
   增项（句子里多出的谐音字被当成条目）与漏项同样判不合格。
4. **保序测试**：随机问“第 5 项是什么”，必须由句子中的位置直接得到。

**步骤（B：配对 → 两点锁定）**

5. **拆两点**：限定词（含类别）+ 专名。
6. **转换专名**：谐音/形象/常识嫁接，选与限定词最容易构成一句自然话的版本。
7. **排除易混项**：列出同类的 2–3 个易混候选，检查所造句子是否会推出它们；会 → 加限定或换联想。
8. **反向测试**：只看专名能否说出限定；只看限定能否唯一推出专名。

**输出契约**：

```
清单/配对名：___   类型：顺序清单 / 配对   条目数：___
歌诀版 1：___   版 2：___
还原测试：条目 ___/___  增项 ___  漏项 ___  判定：通过/不通过
配对表：限定词 | 专名 | 联想 | 易混排除 | 反查
数值采用：不采用原书数值（如需数值，须外部核实）
```

**完成标准**：歌诀一次还原全对（不多不少）；配对双向可推且不推出易混项；
超过 12 项的清单已分组且各组句子互不干扰。

## B｜边界与不适用

- **数值一律不背书**（NR-06 + r07）：原书地壳元素含量表的列序与常见数据不一致，人体元素条目也有错配；
  税法口诀里的税率、扣除比例、罚款倍数为 2017 年前后资料，可能已失效。
  本卡只取“字头谐音成句”“拆两点 + 排除易混”的手法，**数值须由现行教材或权威来源核实**。
- **同字头与条目上限**：原书未给“字头重复怎么处理”“清单最长多少项”的规则；
  本卡的“取第二字”“>12 项分组”是补法，须声明为约定。
- **歌诀会引入多余信息**：为了让句子顺口加进去的字，在还原时可能被误当条目（这是本卡设置“增项”检查的原因）。
- **理解型内容不适用**：把需要论证的内容压成口诀，会得到能背但不会用的结果（作者本人对会计考试的说法是
  “记忆法只是工具，大部分靠理解”）。
- **中文谐音依赖**：跨语言（英文术语首字母）时改用首字母串，但已非作者配方。
- **不做**：不复制原书税法口诀的数值内容；不把口诀当“永久记忆”；不在未核实原清单的情况下压缩。

## 相关能力

关系类型：依赖（用本卡前须先懂它）/ 对比（按情境二选一）/ 组合（常配合使用）。
机器可读的补读清单见 Bundle 中本能力的 `also_read`。

- **组合** `abstraction-conversion` — 谐音成句依赖同一手法族与同一择优标准。
- **对比** `clause-loci` — 歌诀压缩整组、还原靠句子；要按号点背须转 clause-loci。
- **对比** `date-pairing` — 配对到年代走 date-pairing；本卡管文字类清单与配对。
