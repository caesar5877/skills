# 单词复习管理系统（三三原则 + 计数升级）

## R｜来源与依据

原书 P143–P146（学习工具清单、三三原则四条、书写分区、页眉页脚与红线/黑线规则、“正”字计数、早晚检查）。

原文（P144）：

> “把一天分为早上和上午、中午和下午、晚上三个时间段。每个时间段都要记一次……
> 每记一次都要对一组单词记三遍。”

升级规则（P144–P146）：“页脚书写‘正’的一画……用‘正’来记录自己所记忆的次数……
当单词有两条黑线时，用红笔圈起该单词，并用黑笔写在页眉上，只写单词。”

## I｜这条能力在说什么

背单词的真正难点不是“今天记住”，而是“几千个词各自处在什么掌握状态”。这套系统把状态做成
**看得见、可自查的纸面账本**：

1. **三三原则**：一天三个时段各接触一次；每时段对同一组单词记三遍；前三次看词回忆词义，
   **第四次改为看词义拼写**（从“认得出”升级到“写得出”）。
2. **三色笔 + 不透明卡片**：卡片遮挡做闭卷回忆（杜绝“看着眼熟”的误判）。
3. **计数与升级**：
   - 每次记忆在页脚画“正”字一画 → 一眼看出哪词练得少；
   - 回忆失败 → 词下画黑线；**两条黑线 → 红圈并抄到页眉**（只写单词，集中过）；
   - 拼写失败 → 词义上画红线；**两次红线 → 红圈并把词义写到页脚**（先拼页脚词）；
   - 一词多义：前三次只记关键义，之后逐次加义。
4. **早晚检查**：每天早晚核对“正”字笔画数，**笔画少的优先**——同时充当考勤，
   “今天有没有偷懒”不用靠感觉。

这套东西的精神不是仪式感，而是**把复习优先级变成可计算的**：错得多、练得少的词自动浮到最上面。

## A1｜原书案例（作者规则与操作示范，非本卡合成）

- **书写分区示范（P144–P146）**：正文写词与词义，页脚记“正”字与拼写错词义，页眉集中回忆失败词。
- **升级路径示范（P145 附近）**：某词两次回忆不出 → 黑线两条 → 红圈 → 抄入页眉；
  下次只过页眉，过了再回正文。
- **工具清单（P143–P144）**：笔记本、蓝黑红三色笔、不透明卡片，并要求“牢记住记忆馆的大小字母桩”——
  注意：**“记忆馆/字母桩”全书仅此一处提及，未给内容与建法**（NR-01）。
  本卡将其列为可选项，用户可用 `number-code` 的规则自建一套大小写字母桩，不虚构其内容。

## A2｜我的适用表述

**用户处在这些情境**：

1. 单词书翻到第三遍还是熟词熟悉、生词依旧——因为没有优先级。
2. 想知道自己某天到底有没有真的在复习。
3. 认得出但拼不出（或反过来）。
4. 需要一个能坚持的日常流程，而不是“今天状态好就多看两眼”。
5. 一批新词（如某单元 24 个）要建立长期管理。

**语言信号**：“单词怎么安排复习”“一天背几次”“背过的单词怎么筛”“怎么知道自己偷懒了”
“认识但不会拼”“给我一个单词复习流程” / “how to organize vocabulary review”“I only ever re-read the list”
“I know it but can't spell it”。

**与相邻能力的区分**：

- `word-method-select` 决定**第一次怎么建立联想**；本卡决定**之后怎么管**。
- `review-scheduler` 是通用六次间隔排程（可落到日历）；本卡是单词专用的纸面状态账本，粒度到“词”。
  两者可并用：本卡管优先级，排程管时点。
- `mind-map` 的复习五步是“整篇/整章”层面；本卡是“逐词”层面。

## E｜执行

**输入契约**：① 词表（新词或已有词表）；② 每日可用时段数（不足三个时段须调整，见步骤 2）；
③ 目标（认得出 / 拼得出 / 听写 / 应用）；④ 载体（纸面笔记本 / 表格 / 任意间隔重复软件）；
⑤（若为已有进度）现有标记状态。

**步骤**

1. **建载体与分区**：正文（词 + 关键义）、页脚（“正”字计数 + 拼写失败词的词义）、页眉（回忆失败词，只写词）。
   数字工具可用三张视图替代三区。
2. **排时段**：默认早/午/晚三个时段，每时段对同一组记三遍（闭卷回忆），
   **第四次改为看词义拼写**。只有两个时段时改为“两个时段各两遍 + 睡前一次拼写”，并声明为调整版。
3. **建立初始组**：每组 10–20 词（作者未给上限，本卡约定），同组词形相近的词**不要放同一组**
   （形近词互相干扰，见 word-method-select 的词族区分条款）。
4. **每次接触都做闭卷**：卡片遮挡词义，看词回忆；回忆不出 → 黑线一条。
5. **升级判定**（严格按阈值，不凭感觉）：
   - 黑线 2 条 → 红圈 + 写入页眉；下轮先过页眉；
   - 拼写红线 2 次 → 红圈 + 词义写入页脚；下轮先拼页脚；
   - 页眉/页脚项连续三次全过 → 降回正文。
6. **计次与优先级**：每次记忆在页脚该词位置补一画；早晚各检查一次，**笔画最少的前 20%** 进入当天优先队列。
7. **一词多义**：前三次只要求关键义；稳定后逐次加义，不一次摊开。
8. **输出当天清单**：`先过页眉 → 再拼页脚 → 正文按笔画少优先 → 新词按组`。
9. **掌握判定（本卡补的约定）**：正文中连续三轮无新增黑线/红线，且拼写通过 → 移出活跃清单，
   转入月度抽查（原书未给“何时可移出”的标准，须声明为自定义）。

**输出契约**：

```
词表名：___  组大小：___  时段安排：___
当日清单：页眉待过（___ 词）| 页脚待拼（___ 词）| 正文优先（___ 词）| 新词组（___ 词）
状态统计：黑线 ___ 红线 ___ 红圈 ___ 平均“正”字笔画 ___
待自定义项：掌握判定标准（默认：连续三轮无新增标记 + 拼写通过 → 移入月度抽查）
```

**完成标准**：每个词都有可核对的状态（计次、线、圈、区）；当天优先级由数据产生而不是凭感觉；
能在不看历史记录的情况下回答“昨天练了哪些词、练了几次”。

## B｜边界与不适用

- **“记忆馆 / 大小字母桩”原书未定义**（NR-01，仅 P144 一句）：本卡不解释它是什么，
  只把它列为可选工具并给出替代方案（用 `number-code` 的唯一性规则自建字母桩）。
  任何声称“书里有字母桩内容”的说法都是过度推断。
- **纸面流程可以换工具**：原书停留在纸笔与三色笔时代（2017 年，无间隔重复软件）。
  电子化时保留三件事：闭卷回忆、失败升级阈值、按练习次数排序；不必照搬页眉页脚。
- **“三三”不是普适规律**：三个时段、三遍是作者给出的节奏，未经不同材料与年龄的验证。
  时间不够的学习者应缩减组量而不是缩减“闭卷回忆”这个动作。
- **不适用于**：以阅读/听力为主的词汇习得（先要接触量）、需要搭配与语用的词（应放入例句与语境）、
  以及低龄儿童（把计数打卡变成压力会适得其反）。
- **计数不是目的**：出现“为刷笔画而快速划过”的现象时，系统已失效，应减小每日量。
- **不做**：不承诺词汇量增长数字；不用系统替代发音与拼写规则教学；不将“抄写遍数”当复习质量指标。

## 相关能力

关系类型：依赖（用本卡前须先懂它）/ 对比（按情境二选一）/ 组合（常配合使用）。
机器可读的补读清单见 Bundle 中本能力的 `also_read`。

- **组合** `word-method-select` — 先有可记的关联，计数与升级才有对象。
- **对比** `review-scheduler` — 本卡是逐词状态账本（黑线/红线/页眉），review-scheduler 是跨材料的时点排程。
