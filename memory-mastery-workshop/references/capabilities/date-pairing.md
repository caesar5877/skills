# 年代与数据配对（谐音 / 编码 / 推算三径）

## R｜来源与依据

原书 P107–P112：谐音法、编码法（作者称“万能”）、数字归并与推算记忆（逐年、等距、起讫）。

作者的关键限定（P108–P109）：

> “事实上能够用谐音法来记忆的历史年代只是少部分，绝大部分的历史年代是无法谐音的，
> 这时候就需要用到一种万能的方法——编码法。”

推算例（P111–P112）：“唐末农民起义是 874 年开始的，起义持续 10 年，就可推知这次起义是在 884 年黄巢牺牲后失败的。”

## I｜这条能力在说什么

“年代 ↔ 事件”是最典型的**两点无关联**：数字本身没有任何线索指向事件，事件也不含数字。
三径依次尝试：

1. **谐音**：数字恰好能读成有意义的词时才用（1857 → 一把武器；1814 → 一把钥匙）。
   作者自己承认这只覆盖少数。
2. **编码**：其余一律转成 00–99 码（必要时拆成两段）再与事件造联想。
   这是“万能路径”，前提是有可用的码库。
3. **归并与推算**：把孤立的绝对数字换成“基准 + 间隔”。三种算式：
   - **逐年推算**：已知起始 + 持续年数 → 推终点（874 + 10 → 884）；
   - **等距推算**：一串年份同差（1901 / 1911 / 1921 / 1931 / 1941），只记首项与公差；
   - **起讫推算**：记住起讫两端与事件对应关系（美国独立战争八年）。

三径的合用效果是：**需要死记的绝对数字大幅减少**，剩下的都是可推导关系。

## A1｜原书案例（作者例题，非本卡合成）

- **谐音**：印度民族起义 1857——“18”谐音“一把”，“57”谐音“武器”，故“一把武器”（P108–P109）；
  另例 1814 → 一把钥匙。
- **推算（逐年）**：唐末农民起义 874 年起、持续 10 年 → 884 年黄巢牺牲后失败（P111–P112）。
- **等距链（作者列举）**：1901 / 1911 / 1921 / 1931 / 1941 一类同差年份，可只记骨架。
- **起讫推算**：美国独立战争八年起讫关系（P112）。
- 作者对大事年表的处理：以长表清单呈现（P113–P119），属教材性内容，**非方法**（本包不复制清单，r08）。

## A2｜我的适用表述

**用户处在这些情境**：

1. 历史年代背了忘、事件与年份对不上（尤其选择题四个相近年份）。
2. 要记一串年份，感觉彼此孤立。
3. 想少记几个绝对数字，用推理补上。
4. 其他数字型配对（成立年份、发现年份、出版年份）用同一套办法。
5. 已经把年份记混（把 1857 记成 1875），需要纠正机制。

**语言信号**：“历史年代记不住”“年份和事件对不上”“这几个年份老混”“有没有办法少背几个年份”
“年代怎么编” / “I keep mixing up the years”“memorize dates and events”“is there a way to derive these dates”。

**与相邻能力的区分**：

- `number-code` 建码库（前置）；本卡是年代场景的用法决策。
- `abstraction-conversion` 处理文字类配对与转换；本卡处理数字↔事件。
- `mnemonic-list` 把多项压成一句（保序为主）；本卡不追求顺序，追求“两点绑定 + 可推导”。
- `clause-loci` 处理有顺序的条目；年代无序时用本卡。

## E｜执行

**输入契约**：① 事件列表及其年代（**年代必须已核实**）；② 是否单个还是成组；③ 是否有码库且已熟；
④ 考察形式（选年份 / 选事件 / 填空）。缺 ① 的年份不可推断，先让用户补齐。

**步骤**

1. **正确性前置**：核对每个年代（作者警告：逻辑一旦形成，错的也改不了）。
   判停点：来源不可靠 → 不编联想。
2. **试谐音**：数字能否自然读成与事件有关的具体词？能 → 用谐音（最省）。
3. **否则转码**：把年份拆成两段（18｜57）或按位组合，取对应码；
   码与事件造一个动作或一条逻辑，要求**唯一指向**（不能让同组其他事件也被推出来）。
4. **找推算结构**（成组时优先做，收益最大）：
   - 排成一行看差值 → 等距链（记首项 + 公差 + 成员名单）；
   - 有起讫/持续时间的 → 起讫或逐年推算；
   - 因果/先后关系明确的 → 只记锚点年份 + 顺序。
5. **易混分离**：把最易混的两个年代放到同一张卡上比较，
   用**不同的联想通道**（一个用编码画面、一个用谐音或推算），避免同型竞争。
6. **双向测试**：事件 → 年代；年代 → 事件；以及“干扰项测试”（给四个相近年份能否排除）。
   任一失败 → 该条换更强的联想或改走推算。
7. **纳入复习**：调用 `review-scheduler`，把“双向测试”作为复习动作。

**输出契约**：

```
主题：___
表：事件 | 年代(已核实) | 采用路径(谐音/编码/推算) | 联想或推算式 | 正查 | 反查
推算骨架：基准 ___ | 规则 ___ | 覆盖成员 ___（可省去 ___ 个绝对数字）
易混组：___ → 分离方式 ___
```

**完成标准**：正查反查全对；干扰项测试通过；推算链能覆盖的年份不再单独死记；
每条联想唯一指向（不会被同组其他事件套用）。

## B｜边界与不适用

- **不交付年表本身**：原书的大事年表（P113–P119）是教材性清单，随教材版本变化（r08）。
  本卡只交付方法，年代数值须由用户从其教材/考纲取得。
- **年代必须先正确**：在错误年份上编码等于制造顽固错误（作者原话 P059）。
- **推算关系不能凭印象**：等距与持续年数需从权威来源确认，本卡不允许“看起来像等距”就建链。
- **谐音依赖中文读音**：对外语历史（英语人名年份）或方言使用者效果下降。
- **不适合**：需要历史因果与脉络理解的题目——年代只是坐标，本卡不替代理解（作者自设边界：
  纯记忆知识点 ≤30%）。
- **原书数字未标版本**：作者引用数据未标来源版本（批判节已记录）；本卡不复述这些数据作为事实。
- **不做**：不承诺“年代永不混”；不用同一编码图像承载两个相邻年份（唯一性优先）。

## 相关能力

关系类型：依赖（用本卡前须先懂它）/ 对比（按情境二选一）/ 组合（常配合使用）。
机器可读的补读清单见 Bundle 中本能力的 `also_read`。

- **依赖** `number-code` — 编码路径要求码库已达自动反应，否则推算与联想都会被转码拖垮。
- **组合** `abstraction-conversion` — 同一安全门：先核实正确答案，再编“唯一指向”的关联。
- **对比** `mnemonic-list` — 本卡不追求保序，追求两点绑定与可推算；顺序类清单走 mnemonic-list。
