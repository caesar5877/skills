# 有序条款与问答题的数字定位（含载体独占）

## R｜来源与依据

原书 P044–P046（三十六计）、P120–P124（《南京条约》七条、载体复用批评、政治/会计同法）。

作者给出的排除性理由（P124）：

> “如果只记这一个问答题也还是可以的，但如果再用同样的身体部位去记忆另外一个问答题，
> 就很有可能会出现混淆和张冠李戴的情况。”

例题口径（P044–P045）：“1 瞒天过海（1 的代码是蜡烛，我们可以想象有个人点着蜡烛偷偷地瞒着天过海）……
10 笑里藏刀（10 的代码是棒球）”，目标是“一遍记下来并能随意点背”。

## I｜这条能力在说什么

“第 1 条到第 n 条”的材料（条约、法条、检查要点、答题要点、计策名目）难的不是每条的内容，
而是**顺序与定位**：背到第五条想不起前面有几条，抽背第七条就串到第三条。

配方四步：**编号 → 取码 → 码与条目大意造联想 → 按号点背**。数字码在这里充当的不是图像装饰，
而是不会错序、随时可用的槽位——比空间载体更稳（作者：数字载体“熟悉、简单，可以信手拈来”，
不会出现忘记顺序的情况）。

第二个要点是**载体独占**：需要长期保留的题目，必须为它预留一段不与他人共用的码（如第 12 题固定用 61–70）。
身体部位、随机找的物件之所以被排除在长期场景之外，是因为它们容量小、还会跨题互相污染，
甚至要额外记住“这道题当时用的是哪个载体”。

## A1｜原书案例（作者例题，非本卡合成）

- **三十六计 1–10**：1 蜡烛（点着蜡烛偷偷瞒天过海）…10 棒球（笑里藏刀），要求可随意点背（P044–P045）。
- **《南京条约》七条**：第一条“1 蜡烛”→人们点着蜡烛祈祷和平（战争结束）；
  2 鸭子→贩卖、通商口岸；3 耳朵→赔款；红旗→插旗占地（P121–P122）。
- **同类迁移（作者明示）**：政治问答题、会计类要点“同法”可记（P120–P124），并附载体复用批评。
- **反面警告（作者）**：用身体部位记多道问答题会“混淆和张冠李戴”（P124）；
  “万事万物定位法”要额外记住用了什么载体，不科学（P124）。

## A2｜我的适用表述

**用户处在这些情境**：

1. 要背“几条规定/几点原因/几项内容”，顺序一乱就全盘乱。
2. 考试要按点给分，怕漏点、怕点错位。
3. 好几道题都用同类方法，结果互相串。
4. 需要一份能“点第 n 条就答第 n 条”的清单。
5. 问“能不能用身上的部位记，省得建编码”。

**语言信号**：“第几条到第几条”“按顺序背”“点背”“答案有条数”“几条要求怎么记”“背串了”
“多道题会不会混” / “memorize a numbered list”“I mix up the order”“recall item number 7 on demand”。

**与相邻能力的区分**：

- `title-loci` 处理**答案条数少且题干能拆**的问答题（不消耗外部码）；本卡处理条数多、需长期保留的题目。
- `long-text-recall` 处理有连续语流的篇章；本卡处理彼此独立的条目。
- `number-code` 建码库（前置）；本卡是用码的配方。
- `mnemonic-list` 把清单压成一句话；本卡保留每条的独立内容并支持按号提取。

## E｜执行

**输入契约**：① 题目与答案条目（原文，逐条列出）；② 条目数 n；③ 保存期（临时 / 考试长期）；
④ 是否已有码表且已达自动反应；⑤ 已分配的码段（若为长期备考，需避免与其他题冲突）。
缺 ④ 时先派 `number-code`，不得用未熟码硬上。

**步骤**

1. **拆条**：把答案切成互不重叠的条目，每条不超过 15 字；一条含多层时先只取“要点名词 + 动作”。
2. **判定是否走标题定位**：n ≤ 6 且题干能取出 n 个有意义的字 → 转 `title-loci`；否则继续。
3. **分配码段**：长期备考题按题独占一段连续码（例：第 12 题 → 61–70），并在登记表里占位，防止另一题占用。
4. **逐条造联想**：码的图像与条目大意造一个动作或一条逻辑；**动词要直接把条目带上**
   （“3 耳朵 → 赔款：耳朵上挂着钱袋”这类可复述关系）。
5. **点背校验**：
   - 正向：报号答条（1→n 与随机顺序各一遍）；
   - 反向：给条目说编号；
   - 错的那条回步骤 4 改写（多数错因是画面里没有条目本身，或码的图像想不起来）。
6. **与理解配合**：先能说出每条为什么成立（作者：“会计考试大部分靠理解”），再上记忆法；
   否则记住的编号在论述题里用不上。
7. **复习**：调用 `review-scheduler`，把点背作为复习动作（不是重读答案）。

**输出契约**：

```
题：___  条数：n  保存期：___  码段：___（独占登记：是/否）
表：序号 | 码 | 条目(短) | 画面/逻辑 | 正背 | 反查
统计：正背 ___/n   反查 ___/n   待改写条目：___
```

**完成标准**：随机顺序点背全对；反向（条目→编号）全对；码段独占已登记；复习时点已排。
错序或反查失败即未完成。

## B｜边界与不适用

- **不用身体桩承载长期内容**（容量小 + 跨题污染，作者原话见 R 段）；临时十项以内可用，但要在登记表写明
  “临时载体，不长期依赖”。
- **拒绝“万事万物定位法”**：随机物件作为载体需要额外记住用了什么，负担转移而非消除（P124）。
- **码表未熟时不要用**：转码不自动会占掉工作记忆，此时错误会被误判成“方法无效”。
- **码段不独占是本配方最主要的失败源**：两题共用同一段码会在几轮复习后必然串味；
  发现串味时不要“更努力区分”，而是重新分码段并重排复习。
- **原书未给码段分配规则**：如何为几十道题分配互不冲突的码段，原书没有方案；
  本卡的“按题占连续段 + 登记表”是补法，须向用户说明是约定。
- **纯记忆部分之外不适用**：需要推导、计算、组织论述的部分不能交给编号联想。
- **原书数值/条文本身可能过时**：教材版本与法条会变，本卡只交付配方，不背书内容正确性。

## 相关能力

关系类型：依赖（用本卡前须先懂它）/ 对比（按情境二选一）/ 组合（常配合使用）。
机器可读的补读清单见 Bundle 中本能力的 `also_read`。

- **依赖** `number-code` — 码表未过抽测不得上任务：转码会占掉工作记忆。
- **对比** `title-loci` — 条数多、需长期独占载体用本卡；条数少且题干可拆用 title-loci。
- **对比** `mnemonic-list` — 需要按号精确提取用本卡；只要求“整组都在”可用歌诀压缩。
