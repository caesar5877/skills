# 抽象材料转换手法与择优（含造逻辑安全门）

## R｜来源与依据

原书 P033（五种手法）、P049–P051（择优取决于后续对象、科举“愿相会殿”）、P059–P061（“西汉-吸汗”、
租赁三费）、P085–P089（生僻字拆解与错别字造逻辑）。

原文对手法与择准则的表述（P033、P049–P051）：

> “通过谐音、加减字、倒字、替换、望文生义等技巧把那些抽象的、难以理解的信息转换成具体形象……”
> “究竟选择哪一种呢？……取决于后面要与之联系的对象。”

作者的风险条款（P059）：“知识点一旦形成逻辑，哪怕是错的也改不了。”

## I｜这条能力在说什么

联想的前提是手里有个能想象的东西。**转换**就是造这个东西：谐音（西汉→吸汗）、加减字、倒字
（史记→鸡屎 / 腌菜←蔡琰）、替换、望文生义（华盖→滑盖手机）。

关键不在“会不会谐音”，而在**择优**：同一个抽象词往往有三五种可行转换，选哪一个取决于
**后面要跟它连的对象**。作者的两组对照很清楚——“西汉”记成“吸汗”是因为要跟“纸”连
（纸用来吸汗，逻辑成立）；“青城”记成“倾城”是因为后面要说“四川出美女”。转换本身不孤立评价好不好，
只看接不接得上。同音字很多时，选最能与后文组成有意义短语的那个（院试、乡试、会试、殿试 →“愿相会殿”）。

**造逻辑**是转换的另一面：两个毫无关系的信息之间人为编一条因果或功能关系
（租赁要交租金、押金、担保费；“会”做了才算融会贯通；扁鹊治好很多人所以声名“鹊”起）。
逻辑不必正确，只需**唯一指向正确答案**。

安全门是这条能力最重要的部分：**先确认答案正确，再造逻辑**。作者自己指出，学习者凭语感编出来的
“合理但错误”的逻辑（融“汇”贯通、关怀倍“至”）一旦形成就改不掉，纠正只能靠一条更强的新逻辑覆盖，
而不是靠“下次小心”。

## A1｜原书案例（作者例题，非本卡合成）

- **择优（P060–P061）**：“西汉时期发明了纸”——“西汉”转换成“吸汗”或“稀罕”最好，
  因为想到纸会条件反射想到它的功能“吸汗”。换成别的同音词就接不上。
- **同音择优 + 缩句（P050）**：科举四级“院试、乡试、会试、殿试”改成“愿相会殿”
  （“古代考科举的人都但愿最后能够相会在皇帝的大殿里”）；同段另给按等级走“院子→乡里→大会场→大殿”的
  逻辑替代方案，说明两条路径可并存。
- **造逻辑（P061）**：建造师“租赁费用”三项——用租房子的情境一次性串起租金、押金（保证金）、担保费。
- **配对转换（P089–P093）**：文学常识“第一部/第一位”用颠倒、谐音、字面逻辑三类手法
  （蔡琰→腌菜、史记→鸡屎；编年体可行时优先用逻辑）；借代词 21 组先变现代物（华盖→滑盖手机，
  联想到“运气好捡到滑盖手机”）。
- **错例与风险（P088）**：融**汇**贯通、声名“雀”起的错误来自学习者自己造的逻辑；
  作者给的覆盖式纠正：任何知识你“会”做了就是融会贯通；神医扁鹊治好很多人，所以他声名鹊起。

## A2｜我的适用表述

**用户处在这些情境**：

1. 抽象名词、术语、概念“根本想象不出来”，联想无从下手。
2. 已经谐音了，但和要配的对象接不上，反复返工。
3. 成语错别字、生僻字、易混字形反复错。
4. 需要把“类别 ↔ 书名/人名/术语”这类两两配对记住。
5. 担心自己编的联想把错误答案固化。

**语言信号**：“这个词太抽象记不住”“怎么谐音”“帮我编个联想”“老写错别字”“这两个老混”
“我这样编对不对”“会不会记错了改不过来” / “this term is too abstract to remember”“make a mnemonic for”
“I keep writing the wrong character”。

**与相邻能力的区分**：

- `image-placement` 处理“已有画面但不好用”；本卡处理“还没有可想象的东西”。
- `mnemonic-list` 把多条压成一句；本卡处理单个词/单个配对的变形。
- `date-pairing` 是“数字 ↔ 事件”的专用配对；本卡处理文字类配对。
- `word-method-select` 是英语单词场景的选法（其中谐音/拼音分支与本卡同源，但有发音风险限制）。

## E｜执行

**输入契约**：① 待记项（原词，字形必须正确）；② 要与之关联的对象（配对的另一半 / 后续要挂的内容）；
③ **正确答案已经核实**（配对类、字词类必提供，否则本卡拒绝造逻辑）；④ 使用场景（默写 / 选择 / 口答）。

**步骤**

1. **正确性校验（安全门）**：先确认答案、字形、读音正确。
   判停点：无法确认正确 → 停止转换，先让用户查证；在错误答案上编联想等于制造顽固错误。
2. **判断需不需要转换**：本身已具象（桌子、蜡烛）不转；能直接用字面逻辑成立的优先用逻辑
   （编年体→按年代编排），逻辑够用就不要谐音。
3. **产候选**：针对抽象项生成 2–3 个转换候选，标明手法
   （`谐音 / 加减字 / 倒字 / 替换 / 望文生义`），每个候选写出“变出来的具体东西”。
4. **按后续对象择优**：逐个问“它和对象能不能构成一句自然的话、且只指向这个答案”。
   能构成且唯一 → 选它；都勉强 → 换下一批候选或改用逻辑。
5. **配对类加排除项**：显式列出易混候选（“不是高原、不是海拔最高”），
   检查所造逻辑会不会把易混项也推出来；会则改逻辑直到唯一。
6. **字形/读音类加唯一指向测试**：遮住答案，只看提示，问“能不能只推出这一个写法/读音”。
   推出不唯一（同音字多个）就在逻辑里补一个限定（部件、义旁）。
7. **改错处理**：若用户已有错误逻辑，不采取“提醒自己注意”，而是构造一条更强的正确逻辑覆盖
   （作者式做法：给正确字形一个不可替换的理由），并在 24 小时内复测一次。

**输出契约**：

```
待记项：___   对象：___   答案已核实：是/否（否→不产出联想）
候选：1) 手法 ___ → 结果 ___ → 与对象成逻辑？唯一？
      2) …
选定：___（理由：唯一指向 + 与对象自然成句）
易混排除：___
反向测试：只看提示 → 能否唯一推出答案：是/否
```

**完成标准**：由任一侧能唯一推出另一侧；候选中被选中的转换有明确“接得上”的理由；
易混项被显式排除；答案正确性已被确认。达不到则继续换候选，不得用牵强版本凑数。

## B｜边界与不适用

- **最高风险：在错误答案上编逻辑**（作者：“哪怕是错的也改不了”，P059）。本卡把“先核实”设为硬前置，
  不接受“先编一个回头再改”。
- **中文中心**：谐音、拼音、倒字全部依赖汉语音系。方言使用者、非中文母语者效果打折；
  对外语词汇不能直接套（见 word-method-select 的发音风险）。
- **望文生义是双刃剑**：它把字面义当线索，可能强化错误理解（把“差强人意”按字面理解）。
  凡涉及词义的望文生义，必须与权威释义并列，并在 B 段留一句“此仅为记忆钩子，不是词义”。
- **原书例题的牵强性**：书内长例（如《弟子规》180 句逐句转换）转换文本高度个人化、不少地方牵强，
  属练习素材而非可复制标准（references r05）。本卡不把这些牵强转换当范例推荐。
- **原书缺口**：错别字例题的选项在扫描版里有乱码，具体题干须回原书核对（NR 关联，已在覆盖审计标注）；
  本卡只交付“造正确逻辑覆盖错误逻辑”这一手法，不复述可能有误的题目内容。
- **不做**：不为“有意思”而编联想；不代替理解（作者：记忆法只处理纯记忆层面）；
  不承诺“编了就忘不了”（保持仍依赖复习）。

## 相关能力

关系类型：依赖（用本卡前须先懂它）/ 对比（按情境二选一）/ 组合（常配合使用）。
机器可读的补读清单见 Bundle 中本能力的 `also_read`。

- **组合** `image-placement` — 转换产出可想象对象后，由 image-placement 负责落地与排障。
- **组合** `mnemonic-list` — 字头谐音成句与本卡同源，只是作用在整组材料上。
- **对比** `word-method-select` — 本卡的谐音无发音风险约束；英语词形走 word-method-select（含人群限制）。
- **组合** `title-loci` — 题干取字后逐条造联想时用的是同一套手法。
