# 长文背诵六步（含四种载体选路与还原修正）

## R｜来源与依据

原书 P094–P106（六步总结、《沁园春·雪》《少年中国说》《书湖阴先生壁》《凉州词》《荷塘月色》、验收线）。

原文的六步（P094–P095）：

> “（1）通读（字、理解、注释等）（2）确定方法（记忆目的、结果、自身喜好等）（3）记（出图、线索）
> （4）忆（关键词、线索、回忆路径）（5）还原修正（完整版）（6）复习（定时）”

验收线（P106）：“如果可以回忆出百分之八九十，表示你的记忆效果很不错，不要指望用记忆法可以百分之百
一字不漏地记住全文，这是不现实的。”压缩质量的告诫（P096–P097）：只提关键词
“显得太过单薄、生硬，不够丰富，难以将整句话完整地记住”。

## I｜这条能力在说什么

背诵失败多半不是不努力，而是三处技术错误：压缩过度（只剩孤词，撑不起句子）、载体选错
（写景的用了串连，议论的硬画图）、以及把“记住意思”当“能还原原文”。

六步里的关键判断是第 2 步——**按材料性质选载体**：

| 材料特征 | 载体 |
|---|---|
| 长篇且要求有序 / 随机点背 | 地点定位（一句一桩，或一段一点） |
| 条列式、有序、句数可编号 | 数字编码定位（句序 ↔ 码） |
| 短篇写景、能想象出画面 | 图像（简笔画）记忆 |
| 短篇非写景 | 关键词串连（编成有情节的故事） |

第 3 步提的是**关键意思**而不是单个关键词：能代表整句走向的那个短语，必要时保留句式与关系词。
第 5 步**还原修正**把修饰词、句式补回去——这一步决定你能否说出原句而不是大意。

合格线：**回忆出 80%–90%**，不追求一字不漏；长期完整靠复习。

## A1｜原书案例（作者例题，非本卡合成）

- **数字定位**：《沁园春·雪》按句编号取码，第二句“大河上下，顿失滔滔”用 2（鸭子）——
  “鸭子跳进大河里，顿时消失（顿失）在滔滔的江水里了”（P096–P098）。作者还利用文内同音线索（“三/山”）。
- **地点定位**：《少年中国说》15 句 15 地点；长句内部是排比时，先压成“智、富、强、独立、自由、进步”
  几个关键意思，再逐点落到地点上（P099–P102）。
- **图像记忆**：《书湖阴先生壁》四句各画一幅简笔图，把诗句标在景物上，看图忆文（P103）——
  作者限定：只适合“能想象出画面”的写景材料。
- **串连**：《凉州词》逐句抽关键词（葡萄酒、杯子、琵琶、战马、沙场）串成一行军故事；
  现代文《荷塘月色》同理（叶子、裙、白花、明珠、星星、美人、清香、歌声）（P104–P106）。
- **失败模式（作者警告）**：期望一字不漏、或用“短期速度”评判记忆法——作者明说短期内记忆法并不比死记快，
  收益在保持时长与可提取性（P095、P106）。

## A2｜我的适用表述

**用户处在这些情境**：

1. 要背课文、古文、诗词、演讲稿、条文原文，背到中途断篇。
2. 只记得大意，默写时还原不出句子。
3. 纠结“这篇该画图、该编号、还是该串故事”。
4. 被要求能抽背、点背（老师提问第 6 句）。
5. 背完了但几天后归零，想知道是不是方法无效。

**语言信号**：“这篇怎么背”“背古诗/课文/文言文”“背到一半就断”“背到中段就断、前后接不上”“开头滚瓜烂熟后面想不起”“古诗文默写漏句”“记不住原文”“能背大意但写不出原句”
“第几局/第几句是什么来着” / “how do I memorize this passage”“I can't recall the exact wording”“I lose the thread halfway”。

**与相邻能力的区分**：

- `clause-loci` 处理“条目之间彼此独立”的有序清单（条款、要点）；本卡处理**有连续语流的篇章**，
  多出的动作是压缩成关键意思与还原修正。
- `method-routing` 是通用选路；本卡的选路只回答“这篇用哪种载体”，是它的特化。
- `image-placement` 处理画面质量；本卡在写景路线上会调用它。
- `review-scheduler` 负责第 6 步。

## E｜执行

**输入契约**：① 原文全文（含生僻字与注释，需先解决读音与词义）；② 目标：能复述大意 / 能原文默写 /
能被抽背第 n 句；③ 篇幅（句数或行数）；④ 是否需长期保留。目标不同，第 3、5 步的严格度不同，必须先确认。

**步骤**

1. **通读**：读准字音、弄懂注释与文意。**判停点**：存在不理解的句子 → 先解决理解，不理解的句子无法压缩，
   也无法还原。
2. **选载体**（按上表判定，并写明理由）：
   - 句数 ≤ 8 且写景 → 图像；句数 ≤ 8 非写景 → 串连；
   - 句数 9–30 且需保序/抽背 → 数字定位；
   - 句数 > 30、或需随机点背、或多篇并存 → 地点定位（每篇独占一组桩）。
3. **分句取关键意思**：逐句写出能代表该句走向的短语（2–6 字为宜），保留必要的句式关系词
   （因为/而/之/其）；不要压成与句子无关的名词。
4. **与载体联结**：按 `image-placement` 的规则造画面（每桩默认两项；数字码与句意造动作或造逻辑）。
5. **忆**：盖住原文，只看载体（桩序/句序号）复述关键意思串。
6. **还原修正**：由关键意思回到句子，把修饰词与句式补回；与原句逐句比对，
   把还原不出的句子标为“硬伤句”，单独重造画面（通常问题在压缩过度）。
7. **验收**：合卷通背一遍，统计可复述比例。**80%–90% 判合格**；低于 80% 时不要“再多背几遍”，
   回到第 3 步检查是否关键词化过度，或第 2 步载体是否选错。
8. **排复习**：调用 `review-scheduler`，第一次回忆放在记完后 10 分钟内。

**输出契约**：

```
篇名：___   目标：___   载体：___（理由：___）
分句表：句号 | 原句(可截短) | 关键意思 | 码/桩 | 画面 | 还原结果(✔/硬伤)
统计：可复述 ___%  硬伤句：___   合格判定：合格 / 不合格（原因：压缩过度 / 载体不当 / 未复习）
```

**完成标准**：达到既定目标（大意 / 原文 / 抽背）且可复述比例 ≥80%；硬伤句已重造并复测；
复习时点已排；每篇使用的载体已注明独占，不与第二篇共用。

## B｜边界与不适用

- **不承诺一字不漏**：作者明确“百分之百一字不漏……是不现实的”。需要逐字精确（合同、法律条文原文、
  台词逐字稿）的场景，须搭配抄写/校对流程，本卡只把错误率压低并保证不丢结构。
- **短期内记忆法并不比反复读快**（P095）：临考只剩一两小时时，用传统朗读+提纲可能更划算；
  记忆法收益体现在几天到几月的保持与提取。这一预期要在开工前讲明。
- **图像路线的硬边界**：只有能想象出画面的写景材料可用（P104）。议论、说理、抒情材料硬画图会得到空洞画面。
- **理解不能跳**：文言文、专业文献必须先解词解句；本卡的方法建立在“已理解”的前提上。
- **原书未给粒度标准**：“关键意思”的压缩粒度只有示例，没有判定标准。本卡的 2–6 字与“保留句式词”
  是为可执行而定的约定，须按用户实际还原情况调。
- **依赖基建**：数字路线要求码表已达自动反应；地点路线要求桩组已验收。基建未就绪时先补基建（NR-02 亦提醒：
  原书码表取值受 OCR 限制，不能直接引用）。
- **不用于纯理解型任务**（作者自设边界：纯记忆知识点 ≤30%）：赏析、翻译、写作不在本卡范围。

## 相关能力

关系类型：依赖（用本卡前须先懂它）/ 对比（按情境二选一）/ 组合（常配合使用）。
机器可读的补读清单见 Bundle 中本能力的 `also_read`。

- **组合** `image-placement` — 写景路线与“关键意思→画面”的质量控制都由它把关。
- **组合** `review-scheduler` — 背完只算第三步，长期留存靠排定的回忆。
- **对比** `clause-loci` — 本卡处理有连续语流的篇章；条目彼此独立时用 clause-loci。
- **对比** `mind-map` — 导图压结构、不保证逐句复述；要原文还原用本卡。
