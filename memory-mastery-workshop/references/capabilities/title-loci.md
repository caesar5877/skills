# 标题定位（题干即索引）

## R｜来源与依据

原书 P122–P123（王安石变法五条；关键词必须表达题目大意的约束）。作者对这一配方的定义：

> “所谓标题定位，就是用题目的问题作为定位系统，根据答案的数量，从题目里对应找出几个关键词来作为定位系统。
> 所提取出的关键词必须要能够表达题目的主要意思，不然会导致我们只记住了答案而不知道题目。”

## I｜这条能力在说什么

答案只有三四条、五六条时，不必建宫殿也不必占码段——**题干本身就是现成的有序载体**。
从题干取出与答案条数相等的字或词，按它们在题干中的顺序排列，逐字与答案条目造联想。
看到题目，索引自动出现，答案逐条被带出来。

作者给的唯一硬约束：取出来的字必须**能代表题目大意**。否则会出现尴尬的反向失败——
答案背住了，却不知道它属于哪道题（多个题目共用“发展”“意义”这类空泛字时尤其危险）。

适用前提因此很清楚：**答案条数少、题干里有等量的有意义单位**。条数多、或题干本身是空泛短句时，
退回数字定位（clause-loci），别硬拆。

这条配方是本书相对通用记忆术书最省事的一个特色：不消耗外部载体、不占记忆库空间、天然“看题出答案”。

## A1｜原书案例（作者例题，非本卡合成）

- **王安石变法五条**（P122–P123）：题干“王安石变法”五个字对应五条内容，“王”连青苗法——
  “我们可以说大王在田地里种青苗”。其余四字逐条同理造联想，效果是看到题目就能逐条答出。
- **反例警示（作者）**：若所取关键词不能表达题目主要意思，就会“只记住了答案而不知道题目”（P122）。
  原书未给出此类失败的具体案例，仅给出规则；实际风险多发生在题干含通用词（意义、作用、特点）时。

## A2｜我的适用表述

**用户处在这些情境**：

1. 简答题答案三四条，想“看到题就出答案”，不想为它单独建编码。
2. 题目很多但每题条数少，载体（码段/桩组）不够用。
3. 已经出现“答案记得住、题目对不上”的情况，需要修正取字方法。
4. 复习时间紧，需要成本最低的记法。
5. 问“题干里取哪几个字”。

**语言信号**：“简答题怎么记”“看题出答案”“题干取字”“不想建宫殿”“答案和题目对不上”“三五条要点怎么记”
/ “memorize short-answer questions”“use the question stem as cues”“I recall the answer but not the question”。

**与相邻能力的区分**：

- `clause-loci` 用于条数多或需长期独占载体的条目；本卡只用于少量条目且题干可用。
- `abstraction-conversion` 负责“把抽象条目变成可想象的东西”，是逐条造联想时调用的手法。
- `image-placement` 管画面质量；本卡没有地点，索引是题干字，所以画面只需“字 ↔ 条目”两两接触。
- `mnemonic-list` 把多条压成一句话（适合“记住有哪些”，不保证按条对应）。

## E｜执行

**输入契约**：① 题干原文；② 答案条目列表及条数 n；③ 保存期与考试形式（简答/论述）；
④ 是否已有多题共用题干词的冲突情况。

**步骤**

1. **数条数 n**（通常 n ≤ 6 效果好）。
2. **可行性判定**：能否从题干取出 n 个**各有意义、且能唤起该题目**的字或词？
   取不出（题干太短、太抽象、通用词重复） → 判停，转 `clause-loci`。
3. **取字**：优先取题干中的专名、动作词、限定词（“王安石变法”→ 王/安/石/变/法），
   避免通用词（的、意义、作用）；按题干出现顺序排列，形成检索顺序。
4. **逐字造联想**：第 i 个字与第 i 条答案造一个画面或一条逻辑；
   检查两两接触（不能只是“想到那个字旁边有条答案”）。
5. **双向自测**：
   - 正向：只看题干，逐条复述 n 条；
   - 反向：给第 i 条答案，说出它属于哪道题（这一步专治“答案与题目脱钩”）。
6. **冲突处理**：若另一道题也用了同一个字 → 至少一道题换字；换不出来则两道题都转数字定位。
7. **降级方案**：某条始终挂不上字 → 该条单独用 `abstraction-conversion` 变形，或整题转数字定位。

**输出契约**：

```
题目：___   条数 n：___   取字：字1/字2/…（顺序=题干顺序）
表：字 | 答案条目(短) | 画面或逻辑 | 正向 ✔/✘ | 反向 ✔/✘
判定：适用标题定位 / 退回数字定位（原因：题干取不出有意义单位 / 条数过多 / 与它题冲突）
```

**完成标准**：正向能从题干逐条答全；反向能从任一答案说出所属题目；无与他题共用同一取字的情况。
反向失败即视为不适用，退回数字定位而不是反复背。

## B｜边界与不适用

- **条数多时不要用**：原书只在“条数少”的场景给出该配方，且没有给“条数多于题干可取单位时如何拆”的规则。
  硬拆会让取字失去意义，检索反而更慢（这是原书的配方空白，不是本卡推演）。
- **通用词陷阱**：用“意/义/作/用/特/点”这类空泛字做索引，多道题会指向同一批字，必然串题。
- **题干本身无意义或极短**（如“简述其影响”）时不适用。
- **论述题慎用**：标题定位给出的是“有哪些条目”的提示，不替代论证与展开；
  用它开题，内容仍需理解与组织。
- **依赖中文的取字自由度**：本配方假定题干是可拆的单音节语素串，对拼音文字（英文题目）效果显著下降；
  英文场景可改用“关键词首字母串”但已非作者原配方，需自行验证。
- **不做**：不为追求“答案就在题目里”而牺牲条目内容完整性；不承诺考试命中率。

## 相关能力

关系类型：依赖（用本卡前须先懂它）/ 对比（按情境二选一）/ 组合（常配合使用）。
机器可读的补读清单见 Bundle 中本能力的 `also_read`。

- **对比** `clause-loci` — 二选一分界：答案条数与题干能否取出等量有意义的字。
- **组合** `abstraction-conversion` — 某条答案太抽象挂不上字时，先转换再联。
- **组合** `method-routing` — 条数过多或题干无意义时由它把任务改派到数字定位。
