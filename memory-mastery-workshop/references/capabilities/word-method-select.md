# 单词记忆方法选择器

## R｜来源与依据

原书 P154–P167（适用度 70%、字母编码五类来源、拼音法、谐音的限度）、P169–P185（形似归纳：呼朋引伴 /
词族“羊肉串”、词素）、P195–P214（部分提取、对比记忆）、P157（编码唯一性）。

作者的总量判断（P154–P155）：

> “大概只有 70% 的英语单词是比较适合用记忆法去记的，的确有很多单词用记忆法不太合适，
> 反倒是用传统的方法或许更好。”

限度（P166–P167）：“对于中小学生来说，他们本身英文的发音就不太准确……如果过度使用这种谐音法确实会影响到他们。”
取舍（P155）：长词逐个拆分“会导致编码太多……联想的故事太过于牵强……选取有代表性的几个部分，
忽略掉不重要的部分反而会更好”。

## I｜这条能力在说什么

单词记不住的机理是**字母串与中文意思之间没有关联**（P142、P147）。记忆法的动作是补一个中介，
但**不同词形适合不同的中介**，所以这是一台选择器而不是一个技巧：

| 观察到的词形特征 | 方法 | 要点 |
|---|---|---|
| 含可辨的熟词/字母组合 | 字母编码 / 熟词法 | 组合编码也要唯一（P157） |
| 拼写与拼音高度对应 | 拼音法 | 例：siren ≈ 死＋人 |
| 整词能谐音成具体词 | 谐音法 | 只作临时钩子，见发音风险 |
| 有一个形似熟词 | 呼朋引伴法 | policy ↔ police（警察执行政策） |
| 一批形似词成族 | 羊肉串法 | angle/bangle/dangle/tangle：**差异字母下画线**并单独造联结 |
| 有明显词根词缀 | 词素法 | representative = re-pre-sent-ative；作者定位为备用而非主流 |
| 词很长 | 部分提取法 | 只取少数代表性字母作“引爆点”（capsule 取 PS） |
| 近形/近义易混 | 对比记忆 | stare ↔ star；brave ↔ grave |

选择准则只有一条：**联想是否牵强**。牵强就减少编码、换方法，或退回传统方式（作者给的份额：
约 70% 适合，三成不该硬做）。

## A1｜原书案例（作者例题，非本卡合成）

- **字母编码**：`zoo` 像 200（动物园里有 200 种动物）；`clock` = c + lock（锁）（P147 起）。
- **数字 + 字母混合**：`gloom` 像 9100，m 是麦当劳——“吃了 9100 个麦当劳当然会感到很郁闷”（P147 附近）。
- **谐音**：`ambulance` = 俺不能死（P169 前后）。作者同时给出限度条款（见 R 段）。
- **呼朋引伴**：`policy` ↔ 熟词 `police`（警察执行政策）（P175）。
- **词族羊肉串**：angle 词族在差异字母下画线（b→臂→手镯），并配 berry 歌谣（P177–P181）。
- **词素**：`representative` → “回来-向前-派出去-的人”＝代表；`dislike`、`permission` 同类（P182–P185）。

## A2｜我的适用表述

**用户处在这些情境**：

1. “这个单词怎么记”——拿到具体词，要一个可执行的联想。
2. 背单词反复失败，怀疑方法问题（只背中文意思）。
3. 一堆长单词拆不动，或拆完故事更复杂。
4. 形近词成群混淆（adopt/adept/adapt、angle 词族）。
5. 家长/老师关心“能不能用谐音记单词，会不会带坏发音”。

**语言信号**：“这个单词怎么背”“英语单词记不住”“帮我拆这个词”“谐音记单词好吗”“形近词分不清”
“词根词缀要不要背” / “how do I remember this word”“break this word down”“is a phonetic mnemonic safe”。

**与相邻能力的区分**：

- `word-review-system` 管“记住之后怎么不忘”（时段、计数、错词区）；本卡只管第一次怎么建立关联。
- `abstraction-conversion` 是中文材料的转换（谐音/倒字/望文生义）；本卡是英语词形的分支，含发音风险条款。
- `number-code` 提供数字码，用于“数字像字母/字母像数字”的少数词。
- `clause-loci` / `mnemonic-list` 不用于词汇。

## E｜执行

**输入契约**：① 单词（拼写）；② 目标词义（取需要掌握的那个义项）；③ 学习者是否处于发音定型期
（中小学 / 成人）；④ 是否成组出现（词族 / 易混词）；⑤ 词频或考试要求（决定值不值得做联想）。
③ 缺失会影响是否允许谐音，须问。

**步骤**

1. **先判该不该做**：高频、长期要用、且“字母串↔词义”无天然关联的词优先做联想；
   已掌握词根或已会读写的词不必做（作者的 70% 边界）。
2. **按表自上而下匹配**：熟词/组合 → 形似熟词 → 词族 → 词素 → 部分提取 → 拼音 → 谐音。
   优先选**联想元素最少**的那一种。
3. **做牵强度评估**（三项各打 是/否）：
   a. 拆出的部分是否需要绕两个以上弯才连到词义？b. 是否需要保留无意义字母才能讲通？
   c. 三天后仅看词能否还原这个联想？任一为否/是（不利） → 换更少编码的方案。
4. **词族加区分**：同组成形词必须逐词在**差异字母**下画线，并给差异部分单独造联结；
   否则本卡判定该组词不适合成组记忆（作者警告：仅按形似归类“很容易混淆”）。
5. **谐音风险闸**：学习者在发音定型期 → 不采用整词谐音，改用熟词/词素/部分提取；
   成人可用，但注明“谐音只挂钩词义，读音跟读原声”。
6. **产出**：`方法 | 拆解或桥 | 联想句（≤20 字）| 牵强度（低/中/高）| 退回方案`。
   牵强度高的词直接给退回方案（重复+语境阅读+例句），不要硬凑。
7. **批量处理**：一批词时先做 10 个试点，统计可还原率；可还原率低于 70% 说明选法过细，
   整体退回“更少编码 + 阅读语境”。

**输出契约**：见步骤 6 的表；成组词额外输出区分表（词 | 差异字母 | 区分联结）；
不适用记忆法的词单列一栏并写明理由。

**完成标准**：每个词有方法、有联想或明确退回；联想可由词还原（不是由联想才想起词）；
词族有区分；儿童场景无整词谐音；不确定的词被诚实标为“不适合记忆法”。

## B｜边界与不适用

- **不做无差别拆分**：作者点名长词全拆会让故事牵强（P155）。判断标准是“联想元素越少越好”，
  不是“能不能拆”。
- **谐音的代价是明确的**（作者承认，P166–P167）：可能污染发音，对中小学生尤其如此；
  学术写作/口语纠正场景不要用谐音。书里把它当作主力手法之一，本卡把它降级为“最后手段 + 人群限制”。
- **字母编码表取值不可直接引用**（NR-03）：P157–P160 三张表在扫描版里断行严重，逐格对应关系不可靠。
  本卡只给“五类来源 + 唯一性约束 + 组合规则”，具体字母取值请用户自建或回原书 p.137–140 核对。
- **词根表不完整**：原书称常用词根“200 多个”，实际只列 98 条；不能宣称“书里给全了”。
  词素法需要外部词根资料，本包不代填（属外部事实）。
- **不替代拼写与发音训练**：联想解决“词形↔词义”，拼写规则、读音、搭配要靠读与写。
- **原书示范库属练习素材**：数百条逐词拆解示范（r06）质量参差，本卡仅抽样作例，不整表复制，
  也不把其中牵强条目当标准。
- **不做**：不承诺词汇量增长幅度；不给低频词做长联想（成本高于收益）。

## 相关能力

关系类型：依赖（用本卡前须先懂它）/ 对比（按情境二选一）/ 组合（常配合使用）。
机器可读的补读清单见 Bundle 中本能力的 `also_read`。

- **对比** `abstraction-conversion` — 中文材料的转换在这里换成英语词形规则，并多出“发音定型期慎用谐音”一条。
- **组合** `word-review-system` — 本卡负责第一次建立关联，那张卡负责之后不忘。
- **组合** `mnemonic-list` — 词族歌谣（如 berry 系列）属同一压缩手法。
