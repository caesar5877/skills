# 记忆品质四维自评与瓶颈定位

## R｜来源与依据

原书 P013–P020（记与忆是两个过程、三种记忆时程/容量/遗忘原因、四维品质）、P022（无效重复）、
P095 与 P106（预期校准）。

原文（P017–P019）：

> “一个人的记忆力水平，可以从记忆的敏捷性、持久性、正确性和备用性四个方面来衡量和评价……
> 记忆的备用性是决定记忆效能的主要因素。”

配套口径（P015–P016 表格转述）：瞬时记忆（图像 0.25~1 秒）、短时记忆（1 分钟以内，广度平均 7±2 个，
因干扰而忘）、长时记忆（永久、容量无限，**因缺乏回忆线索而忘**）。

## I｜这条能力在说什么

“我记性差”是不可执行的一句话。作者把记忆拆成两个可分别失败的过程（**记**与**忆**），
再用四个维度定位：

| 维度 | 含义 | 掉分时的手段 |
|---|---|---|
| 敏捷性 | 单位时间记住多少（快慢） | 集中注意；把新材料接到已有知识上再记 |
| 持久性 | 保持多久 | 提高首次有效刺激 + 复习密度（转 `review-scheduler`） |
| 正确性 | 内容不失真、不张冠李戴 | 检查联想是否唯一指向、编码是否混淆（转 `image-placement`） |
| 备用性 | 按需迅速准确提取 | **问题在检索线索**（桩/码/关键词），不在储存量 |

作者把**备用性**放在最高位置：提不出来的记忆等于没有价值。这解释了一个常见误判——
“我背过但想不起来”常被理解为“记性不好”，而按作者框架，这是**线索问题**，修法完全不同于“再背三遍”。

还有一层校准作用：选择题考的是**再认**（“一看就知道”），简答与默写考的是**再现**；
两者难度不同，用再认的成绩去推断再现能力会高估自己。

**注意本卡没有量表**：作者只给维度与方向，没有测量工具与评分标准。所以本卡输出的是
“症状归类 + 下一步该做哪个能力”，不是分数。

## A1｜原书材料与标记演练

- **作者的口径来源（引用/转述）**：四维评价（P017–P020）；三时程与 7±2 广度（P015–P016 表格转述）。
  这些是通用心理学口径的作者转述版，**未标注原始出处**。
- **机制叙述（不可当依据）**：P042 的“记忆中枢细胞质量决定记忆力”“训练改的是大脑刷新能力”，
  以及“记忆法像硬件、训练像软件”的类比，均无出处（r09）。本卡不使用它们做因果解释。
- **作者切割的说法（反例）**：“右脑开发/右脑记忆”被作者本人判定为不准确（P042），
  自评时不应把效果归因于这类话术。
- **合成演练（本卡设计，非书中案例）**：用户描述“背得快，但三天后想不起来，而且能想起画面却对不上条目”。
  按四维归类：**持久性**（三天崩）＋**正确性/备用性**（画面在、指向失）双重问题 →
  先修联想唯一性（`image-placement`），再排复习（`review-scheduler`）。
  原书给了四维定义与各维改善方向，但未提供此类完整自评案例，故此演练为本卡编排。

## A2｜我的适用表述

**用户处在这些情境**：

1. 笼统的自我否定：“我记性越来越差了”“我天生记不住”。
2. 具体但不知归哪类：背得慢 / 忘得快 / 记错 / 想不起来，四种混在一起说。
3. 已经用了方法（甚至建了宫殿）但效果不稳，需要判断是哪一环。
4. 想开始训练，不知道该先练什么。
5. 怀疑自己是不是有病（本卡只归类，不评估病理）。

**语言信号**：“我记性差怎么办”“背得快忘得快”“明明记得却说不出”“想不起来但看着眼熟”
“我该练什么”“是不是年纪大了记忆力不行了”“用了某个方法一个月没效果，是方法不适合我还是我没做对” / “my memory is bad”“I recall it but can't retrieve it”
“what should I train first”。

**与相邻能力的区分**：

- `method-routing` 回答“用什么方法记”；本卡回答“已经失败了，失败在哪一环”。
- `image-placement` 有具体的五类画面故障；当症状明确属于画面时可直接走那张卡，不必先过本卡。
- `review-scheduler` 是持久性问题的下游手段。
- `speed-training-plan` 在归因完成后安排练级；本卡不做训练计划。

## E｜执行

**输入契约**：① 一次或几类具体的失败描述（**必须包含材料类型与时间线**：怎么记的、
多久之后失败、失败成什么样）；② 使用者的年龄段与用途；③ 是否正在使用某种方法（用了什么）。
仅有“我记性差”而无具体事例时，先要求举一个真实例子，否则不给结论。

**步骤**

1. **还原事实**：材料类型、原始量、使用的记法、间隔、失败时的具体表现（空白 / 串位 / 张冠李戴 /
   眼熟但说不出）。
2. **区分“记”与“忆”**：
   - 当下就记不进（读三遍仍无法复述第一次内容）→ 记的环节：注意、编码、材料未简化；
   - 当时能复述、后来出不来 → 忆的环节：线索、复习、干扰。
3. **判再认 / 再现**：给提示能认出（眼熟）是再认；必须自己说出是再现。
   只有再认水平时不要宣称“已经记住”。
4. **归入四维**（可多维）：慢 / 忘 / 错 / 提不出，并写下归类依据。
5. **映射手段**：
   - 慢 → 先简化（`four-step-flow` 第 1 步）与集中注意，不在未理解材料上求快；
   - 忘 → `review-scheduler`（重点检查是否从未做过“记后 10 分钟”的抢救回忆）；
   - 错 → `image-placement`（联想唯一性、编码冲突）与 `abstraction-conversion` 安全门（是否在错误答案上编了逻辑）；
   - 提不出 → 检查检索线索是否存在且有序：没有桩/码/关键词 → 转 `palace-building` / `number-code` / `clause-loci`。
6. **排除方法外因素**（本卡的诚实部分）：睡眠、压力、多任务、材料未理解、练习量不足——
   这些原书基本没讨论，但常常是主因。若怀疑，先修这些，再谈方法。
7. **定复测**：给出一个可测的复测（例：“同一难度材料 40 位，两天后抽背”），一周后重跑本卡比较。

**输出契约**：

```
事实：材料 ___ | 记法 ___ | 时间线 ___ | 失败表现 ___
判定：记 / 忆；再认 or 再现；维度：敏捷 / 持久 / 正确 / 备用（可多选，附依据）
主因假设：___（方法环节 or 方法外因素）
下一步：1) ___（能力名） 2) ___ 3) ___
复测：___（同难度、同材料类型，___ 天后）
声明：本结果为症状归类，非测量分数；如怀疑病理请走专业评估
```

**完成标准**：给出维度归类且有依据；输出至少一个具体后续能力动作；包含复测设计；
包含“非测量”声明；未把机制断言（海马回/右脑等）当作解释。

## B｜边界与不适用

- **无量表，不产分数**：作者只给四个维度与方向，没有测量工具。任何“你的记忆年龄是 XX”式输出都超出
  本书依据，本卡禁止。
- **不做病理判断**：疑似失智、脑损伤后记忆障碍、药物或情绪导致的记忆下降，不在此范围，应建议就医。
  原书受众假定为健康学生，未讨论任何病理或注意力障碍。
- **不用于评判他人**：四维是对自己学习过程的诊断，不能用来评价某个人的智力或能力
  （把群体或个体差异当结论是作者立场盲点之一）。
- **警惕“记块/感块/原块/忆块”**：这是作者自造的解释模型（仅 P013 一节出现、无出处，g12/r01），
  可以当沟通话术，不可当科学事实引用。
- **预期校准**：作者明说记忆法在**短期内不比死记快**，也不保证一字不漏（P095、P106）。
  自评若以“这周怎么还没变快”为标准，结论会是错的——标准应是“两周后还能不能提取”。
- **不做**：不承诺改善幅度；不在缺少具体事例时给结论；不把“备用性最重要”曲解成“只要提取快就是记性好”。

## 相关能力

关系类型：依赖（用本卡前须先懂它）/ 对比（按情境二选一）/ 组合（常配合使用）。
机器可读的补读清单见 Bundle 中本能力的 `also_read`。

- **对比** `method-routing` — 本卡在失败之后做归因；选路错属于事前问题，交给 method-routing。
- **组合** `image-placement` — 正确性/备用性掉分多落在画面唯一性与线索质量上。
- **组合** `review-scheduler` — 持久性掉分的首要修法是补上“记后 10 分钟”的抢救回忆与间隔。
