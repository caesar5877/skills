# 思维导图绘制与四场景应用

## R｜来源与依据

原书 P215–P234：定义、线性笔记的两个缺陷、绘制规则与错例、复习五步、决策与流程案例。

绘制规则的关键句（P225–P229）：

> “主干要画粗一些的流畅线条，词要写在线条上面，不可以压住线条……每个线条只写一个词，最多两个……
> 所有的分支都必须在分支处分出来，不能够在线条的中间画出分支来。”

复习五步（P229 前后）：“第一步：努力回忆。复习时先不要翻书……第五步：把修改后的思维导图再仔细地在
脑海中复习一遍。”补漏规则（P231–P232）：“对于当天学习的新知识，一定要在当天复习……
如果有遗漏的，就在思维导图上面用另一种颜色的笔添加上去。”

## I｜这条能力在说什么

这是全书**唯一不依赖编码记忆**的第二套体系：它管的是信息结构，不是记忆钩子。

作者对线性笔记的诊断是结构性的：逐条抄写让**关键词被淹没**在信息量里，层次不清，
既不利于复述也不利于联想（P220–P221）。导图的替代方案是“关键词 + 图形 + 层级 + 颜色”，
让每一层的归属关系一目了然。

十条绘制规则（可直接当检查表）：① 有中央图像且用三色以上；② 主干粗、线条流畅；③ 词写在线上、
线略长于词、不压线；④ **一线一词**（至多两词）；⑤ 分支间距适中（写得下字）；⑥ **分支只能从节点分出**，
不得在线条中间分叉；⑦ 线条彼此相连不断开、由粗到细；⑧ 整体轮廓近圆、无突出边角；
⑨ 印刷体、字横写、纸横放；⑩ 图形清晰、保留个人风格。

四个使用场景：**归纳总结**（把一堆零散词按层级归类）、**复习五步**（回忆→画→延伸→**异色补漏**→脑内再复习）、
**决策**（把选项的优缺点与限制因素画出来推导）、**流程制定**（把活动逐层展开）。

其中最有价值的是复习五步的**异色补漏**：先闭卷画，再对照原始材料用另一种颜色补，
漏过的部分在图上永久显眼——这实际上是把“回忆测试”可视化了。

## A1｜原书案例（作者例题，非本卡合成）

- **归纳（P229）**：给 14 个零散词（机动车、人工制品、打击乐、大提琴、铜鼓、福特车、乐器、小汽车、
  弦乐、中音小提琴、机器、定音鼓、小提琴、小鼓）按层级归类成图。
- **课文结构（P230 前后）**：小学课文《蜜蜂》按“总介绍 / 种类 / 习性”画结构图。
- **决策（P232–P233）**：买新车还是二手车——把优缺点、限制因素画出来再推导结论。
- **流程（P233–P234）**：年度晚会六大板块逐层展开。
- **错例清单（P226–P227）**：主干过长分支过短、词压线或超线、分支从线条中间分出、分支间距太窄写不下字。
- **注意**：原书大量范例是图片（P222–P224、P233），扫描版内文残缺，**无法还原成可复制的成品样例**（r12）。
  本卡不复制成品图，只交付规则与场景流程。

## A2｜我的适用表述

**用户处在这些情境**：

1. 笔记记了很多但复述不出来、重点被淹没。
2. 要用导图整理一本书/一门课/一次会议。
3. 自己画了导图，想知道画得合不合格（常见是层级混乱、一线多词）。
4. 想用导图复习，但只是照着书抄了一遍图（没有闭卷）。
5. 要做选择（两三个方案的取舍）或梳理一个活动流程。

**语言信号**：“思维导图怎么画”“帮我整理成导图”“我的导图对不对”“怎么用导图复习”
“笔记没重点”“做决策能不能画图”“会议流程梳理” / “how to draw a mind map”“organize my notes visually”
"mind map for decision making"。

**与相邻能力的区分**：

- `review-scheduler` 管“什么时候复习”；本卡的复习五步管“一次复习怎么动作”（可与之叠加：
  在排定的时点执行闭卷画 + 异色补漏）。
- `long-text-recall` 是把文本背下来；本卡是把内容结构压成一张图，不保证逐句复述。
- `four-step-flow` 第 1 步（通读简化）可以用导图做压缩工具。
- `word-review-system` 是逐词管理，不用导图。

## E｜执行

**输入契约**：① 主题或一堆原始材料（文本/议题/选项）；② 用途（归纳 / 复习 / 决策 / 流程）；
③ 载体（纸 / 任意导图软件）；④（复习场景）原始教材或笔记的位置，用于补漏对照。
用途不同流程不同，缺 ② 先问。

**A. 绘制与校验（所有场景通用）**

1. 纸横放，中心放**图像**（不是纯文字），准备三色以上。
2. 画一级主干（由粗到细、流畅），每根主干写**一个关键词**，词在线上、线略长于词。
3. 逐层展开：**新分支只能从节点分出**；分支间距留够写字的空间。
4. 收尾检查轮廓：整体近圆、无突出边角；线条彼此相连不断开；用印刷体、字横写。
5. **规则自查表逐项判定**（十条），任一项 ✘ 就重画那一处，不要“下次注意”。

**B. 归纳总结**

6. 把原始条目全列成同级节点 → 找归类维度 → 重组为层级（例：机器 → 机动车/乐器… → 弦乐/打击乐 →
   小提琴/中音小提琴）。判据：每个叶子节点只属于一个父节点，无重复、无遗漏。

**C. 复习五步（最容易被做错的一个）**

7. **先闭卷回忆**：不翻书，凭记忆画主题与分支（这一步是测试，不是整理）。
8. 能画多少画多少，卡住的地方标出来。
9. 翻原始材料对照，**用另一种颜色的笔**添加遗漏与更正。
10. 当天完成（作者硬规则：当天学的内容当天复习）。
11. 最后把修改后的图在脑中再走一遍；异色部分作为下一轮复习的重点。

**D. 决策**

12. 中心写待决事项，一级分支为各选项；每个选项下分“优点/缺点/限制条件/不可逆后果”。
13. 图上标出哪些限制是不可动摇的；结论从图上读出来（若图上无法区分，说明缺信息，先去补信息）。

**E. 流程制定**

14. 中心为活动名，一级分支为板块，逐级展开到可执行的动作项，每项写负责人或时间。

**输出契约**：一张图（或图的文本大纲：`层级1 > 层级2 > 关键词`）+ 规则自查表（10 项 ✔/✘）；
复习场景另需输出“异色补漏项清单”（即本轮回忆缺口）。

**完成标准**：自查表十项全 ✔；归纳场景无重复无遗漏；复习场景确为**先闭卷后对照**（顺序颠倒即无效，
因为无法测出缺口）；决策场景能指出不可动摇的限制条件。

## B｜边界与不适用

- **范例图不可复制**：原书示例多为图片，扫描版 OCR 残缺（r12）。本卡不能给“照着画成这样”的成品，
  只能给规则；首次使用建议对照自查表而非模仿图。
- **导图不是记忆术**：作者自己把它定位为“信息结构化工具”，不承诺记住内容。
  需要精确复述时须叠加 `long-text-recall` / `clause-loci` / `review-scheduler`。
- **规则不是审美**：一线一词、分支只从节点分出、词不压线，这三条之所以严格，是因为它们承载层级归属；
  其余（颜色、图形风格）可保留个人风格（作者明示“保留个人风格”）。
- **不适合**：需要线性论证的写作（论文推导链）、时间轴极强的内容（甘特图更合适）、
  以及超过几十个工作项的复杂系统（应拆成多张图）。
- **软件等价性**：原书假设纸笔（2017 年，无电子化讨论）。软件可以完成同样规则，但“闭卷回忆”这一步
  很容易被替换成“边看边拖拽”，那样就失去测试作用——这是电子化时最主要的失效点。
- **不做**：不用图代替理解；不把图画得炫而丢掉关键词；不在复习场景抄书成图。

## 相关能力

关系类型：依赖（用本卡前须先懂它）/ 对比（按情境二选一）/ 组合（常配合使用）。
机器可读的补读清单见 Bundle 中本能力的 `also_read`。

- **组合** `four-step-flow` — 本卡可充当第一步的压缩与归类工具。
- **组合** `review-scheduler` — 复习五步应在排定的时点执行，异色项即下一轮重点。
- **对比** `long-text-recall` — 本卡管信息结构、不承诺逐句复述；要原文走 long-text-recall。
