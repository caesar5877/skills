# 记忆任务诊断与方法选路

## R｜来源与依据

原书 P022–P026（一个中心 / 两大原则 / 四个步骤）、P040–P048（四类定位载体）、P065（数字长短分流）、
P104（图像法边界）、P124（载体边界）、P154–P155（适用度）。

作者对载体的抽象（P040）：

> “其实并不是只能用房间或者宫殿里面的场景，只要是我们自己熟悉的，能够提前记在脑海中的事物都可以作为载体。
> 因此，我们又延伸出了很多其他的定位法——身体定位法、数字定位法、地点定位法、标题定位法。”

同一章给出的分流依据（P065）：短小数字“用地点定位法就显得有些麻烦了……用编码串连法更加简单快捷”；
而“超长的天文数字，编码法是行不通的，这时候需要采用地点定位法”。P104 划图像法边界：“只有那些是写景，
能够让人想象出画面的文章信息才适合转换成图像来记。”P124 划载体边界：同一批身体部位用于第二道题
“就很有可能会出现混淆和张冠李戴的情况”。

## I｜这条能力在说什么

拿到材料先别背，先做四个判断：**要存多久、要不要保序、要不要随机提取、有多少条**。这四个判断决定载体，
载体决定后面所有工作的成败。

四条主路：短小琐碎、不需保序 → 串连法；有序条款（第 1 条到第 n 条）→ 数字编码定位；
海量且要随机点背 → 地点桩；答案条数少且题干可拆 → 标题定位；临时且不超过十项 → 身体桩（仅此用途）。

还有一道更靠前的门：**这条知识该不该交给记忆法**。作者的自设边界是“只对完全不需要理解、纯粹处于记忆层面的
知识点有效”——专业知识里这部分一般不超过 30%，英语单词约 70% 适用。判断型、推导型、鉴赏型内容硬套记忆法，
是把时间花在不需要记的东西上。

输出的不是一句“用宫殿”，而是四件套：**方法 + 理由链 + 载体需求 + 退回方案**。

## A1｜原书案例（均为作者所给例题，非本卡合成）

- **有序条款 →数字码**：三十六计 1–10 计，1 瞒天过海配“蜡烛”（点着蜡烛偷偷瞒着天过海），10 笑里藏刀配“棒球”
  （P044–P045），目标是“一遍记下来并能随意点背”。
- **数字长短分流**：手机号 `131562187978` 转码后串成一个故事（医生拿鹦鹉喂牛），不必动用地点（P065）；
  而 40 位无规律数字改用 10 个地点、每地点 4 位（P065–P067）。
- **写景短文 → 图像**：《书湖阴先生壁》四句各画一幅简笔图，把诗句标在景物上（P103）；同页警告非写景诗不适合。
- **题干可拆 → 标题定位**：“王安石变法”五个字对五条答案，“王”连青苗法（大王在田地里种青苗）（P122–P123）。
- **临时少量 → 身体桩**：从头到脚十个部位记十个词（P043），作者同时点名其容量弊端。

## A2｜我的适用表述

**用户处在这些情境**：

1. 手头有一份材料（清单、条款、课文、单词、年份、数据），不知道从哪种方法入手。
2. 已经背过但反复失败，想知道是“记性差”还是方法选错。
3. 有明确的使用要求：要按顺序背、要随点随背、要长期保留到考试、还是今天用完就扔。
4. 面对大量内容，不确定值不值得投入建编码/建宫殿的成本。
5. 犹豫某门课（会计、法律、专业课）能不能靠记忆法过关。

**语言信号**：“这个怎么背”“这段用什么方法”“为什么我背了忘”“要按顺序/点背”“长清单怎么记”
“这些要不要背”“记忆法对付得了 XX 吗”“不知道从哪儿开始背，先定个背法”“法条和单词混在一起怎么安排先后” / “how do I memorize this”“which technique should I use”
“will spaced repetition help”。

**与相邻能力的区分**：

- `palace-building` 解决“载体本身怎么建、合不合格”；本卡只判定“需要哪种载体”，不建桩。
- `clause-loci` / `title-loci` / `long-text-recall` 是选定方法之后的具体配方；本卡在其之前。
- `four-step-flow` 是整条流程（含简化与复习）；本卡只负责其中“选择方法”这一步，但把它做严。
- `self-check` 处理“已经用对方法却仍失败”的四维归因；本卡处理“还没开始，先选路”。

## E｜执行

**输入契约**：

| 字段 | 必填 | 说明 |
|---|---|---|
| 材料样本 | 是 | 至少给出条数与 2–3 条实际内容，不能只说“很多知识点” |
| 保存期 | 是 | 一次性（今天）/ 数月（考试）/ 长期保留 |
| 提取要求 | 是 | 顺序背 / 随机点背 / 看题出答案 / 只要认得出 |
| 条目量 | 是 | 条数或字数；数字串给位数 |
| 现有载体 | 否 | 是否已有码表、桩组；没有则本卡须判“先建基建” |
| 使用者 | 否 | 是否发音未定型的儿童（影响谐音类方案，见 word-method-select） |

缺“保存期 / 提取要求 / 条目量”任一项时**先问，不要静默猜值**——这三项直接改变结论。

**步骤**

1. **适用性判定**：这条内容是纯记忆条目，还是需要理解/推导/鉴赏？后者 → 声明不适用，只把其中可剥离的记忆
   条目（术语定义、公式、法条编号）继续往下走。判停点在此。
2. **四项打标**：保存期、是否保序、是否随机提取、条目量。逐条标注，不要凭整体印象。
3. **按表选路**：
   - 不保序 + 条目 ≤ 7 → 串连法；
   - 保序 + 长期 → 数字编码定位（需码表）；
   - 随机提取 或 条目 > 30 或 数字 > 60 位 → 地点定位（需桩组）；
   - 问答类且答案 ≤ 6 条、题干能取出等量有意义的字 → 标题定位；
   - 临时（当天用完）且 ≤ 10 项 → 身体桩。
4. **载体可用性检查**：所需码表/桩组是否已记熟（能默背、能自动反应）？否 → 输出“先建基建”的子任务，
   并说明为什么不能现在硬上（转码会占掉工作记忆）。
5. **独占性检查**（长期材料必做）：该载体是否已被别的材料占用？占用 → 另分码段或另建宫殿。
6. **输出四件套**并给出失败信号与退回方案（例：串连中途断线两次以上 → 升级为数字定位）。

**输出契约**：一张表，字段＝`条目范围 | 保存期 | 保序 | 随机提取 | 选定方法 | 需要的载体 | 退回条件`；
表下附一段不超过 5 行的理由链，必须能指回原书条件（P040–P048 / P065 / P104 / P124）。

**完成标准**：任一条材料都能在 30 秒内产出四件套；同类材料重复判定结果一致；
没有把理解型内容判给记忆法；没有指定使用者并不具备的载体。

## B｜边界与不适用

- **不要用于理解型任务**：作者原话是“记忆法并不是万能的”，并点名“记忆大师考会计百分百过”属误解（P005、P134）。
  需要计算、推导、写作、鉴赏的内容，本卡只负责剥离出其中的纯记忆条目。
- **原书未给阈值，本卡给的阈值是约定**：数字“多长算长”原书只给了直觉（电话号码 vs 天文数字，P065）。
  本卡的“≤7 串连、>60 位上桩”是便于执行的操作约定，不是作者数据，换材料须重新校准。
- **作者留下的配方空白**：既需理解又要精确复述的“混合型知识”（现实中最常见），原书没有配方；
  遇到时须声明这是书的空白，不要假装书里有答案。
- **中文中心**：四类载体里凡依赖谐音/拼音的分支，对方言者、非中文母语者效果打折（见 abstraction-conversion 的 B）。
- **失败模式（作者亲自警告）**：串连串太长→断线全忘（P040）；非写景材料硬画图→画面空洞（P104）；
  身体桩/“万事万物桩”用于长期保存→跨题张冠李戴（P043–P044、P124）。这三条正是本卡存在的理由。
- **不做**：不替用户决定“要不要背”，只给判定依据；不承诺记忆效果，效果的检验在执行方的复测里。

## 相关能力

关系类型：依赖（用本卡前须先懂它）/ 对比（按情境二选一）/ 组合（常配合使用）。
机器可读的补读清单见 Bundle 中本能力的 `also_read`。

- **组合** `four-step-flow` — 本卡是四步流程中“选择方法”一步的展开；整条交付线在那张卡上。
- **对比** `self-check` — 本卡判“这批材料该用什么”（事前）；self-check 判“已经失败在哪一环”（事后归因）。
- **组合** `palace-building / number-code` — 判定需要空间载体或数字载体后，由这两张卡把载体真正建成并验收。
