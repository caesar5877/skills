# 记忆方法概览

> `.cangjie/capabilities/book/overview.md`：随编译产物分发的书级概览与背景资料。
> 工作目录内的完整审计件是 `BOOK_OVERVIEW.md`（阶段 0）、`verified.md`（阶段 1.5）、
> `coverage-audit.md`（覆盖审计）、`references.md` / `needs-review.md`。
> **页码一律为 PDF 页码 P0NN**（印刷页 ≈ PDF − 19）。

## 基本信息

- **类型**：实操手册（训练型方法论）+ 分学科应用案例集；原理部分是心理学常识级铺垫，主体是“配方 + 例题”
- **来源状态**：本包由用户提供的**纯扫描版 PDF 经 OCR** 蒸馏而成，表格与图片内文字有结构性损失（见文末“来源与可信度”）

**一句话主旨**：记不住多半不是脑子笨，而是信息之间缺关联——把材料先简化、转成人能想象的图像、
挂在一个有序熟悉且可反复检索的载体（编码 / 地点 / 题干）上，再按遗忘曲线定时复习，
普通人经定量训练就能记得牢、不乱序、可随机提取；**但它只解决“纯记忆层面”的那部分知识，不替代理解**。

## 骨架（作者论证的七个板块）

1. 记忆怎么运作（Ch1）：记与忆是两个过程；识记-保持-再现/再认；瞬时/短时/长时；记忆有选择性；四维品质（备用性最重要）
2. 操作总纲（Ch2§1）：一个中心 + 两大原则 + 三个代表 + 四个步骤 + 五种能力
3. 工具箱（Ch2§2）：联想 → 串连法 → 定位法（身体/数字/地点/标题）+ 文字转换五法 + 00–99 编码 + 选桩三原则
4. 极限验证（Ch3）：5 分钟 100 数字、2 分钟一副扑克、四个电视项目——同一套“转码 + 定位”动作
5. 学科应用（Ch4–Ch7）：语文（生僻字、错别字、作品集、古诗文五法）、历史（年代三径、问答题两法）、地理生物（配对、歌诀）、会计税法（口诀）
6. 英语单词专章（Ch8，约 70 页）：三三原则与纸面管理 + 六种方法 + “约 70% 适用”
7. 延伸工具（Ch9）：思维导图（绘制规则 + 归纳/复习/决策/流程）

板块关系：1→2→3 递进，4 是 3 的压力测试，5–6 是并列应用，7 是并列延伸（管结构、不管编码）。
整体是“总—分”式操作手册，不是层层论证的学术著作。

## 能力地图（18 项，按主题分组）

**选材与编排**
- `method-routing` 记忆任务诊断与方法选路 —— 一切请求的第一站
- `four-step-flow` 记忆四步总流程 —— 交付主线（编排其他能力）

**载体基建**
- `palace-building` 记忆宫殿（地点桩）建造与体检 ★用户重点
- `number-code` 00–99 数字编码库建立与校验

**联想质量**
- `image-placement` 画面放置与联想质量校验（含五类排障）★用户重点
- `abstraction-conversion` 抽象材料转换手法与择优（含造逻辑安全门）

**具体配方**
- `clause-loci` 有序条款与问答题的数字定位（含载体独占）
- `title-loci` 标题定位（题干即索引）
- `long-text-recall` 长文背诵六步（四种载体选路 + 还原修正）
- `date-pairing` 年代与数据配对（谐音 / 编码 / 推算）
- `mnemonic-list` 清单压缩（字头歌诀 + 配对锁定）
- `word-method-select` 单词记忆方法选择器

**保持与训练**
- `review-scheduler` 复习排程（六次间隔 + 抢救窗口 + 回忆式复习）
- `word-review-system` 单词复习管理系统（三三原则 + 计数升级）
- `speed-training-plan` 数字与扑克训练计划（读码门槛 + 里程碑）

**规模与诊断**
- `mass-task-mapping` 海量任务的载体映射（任务降维）★用户重点
- `mind-map` 思维导图绘制与四场景应用
- `self-check` 记忆品质四维自评与瓶颈定位

## 推荐学习顺序（由依赖关系推出）

1. `self-check`（先知道问题在哪一维）→
2. `method-routing`（学会选载体）→
3. 基建：`number-code` ＋ `palace-building`（先过各自的验收闸）→
4. `image-placement`（画面质量，决定前面两步值不值）→
5. 按需求选配方：`clause-loci` / `title-loci`（应试条款）、`long-text-recall`（篇章）、
   `word-method-select` ＋ `word-review-system`（词汇）、`date-pairing` / `mnemonic-list`（零散知识）→
6. `review-scheduler`（把一次性记忆变成长期留存，所有配方的收尾）→
7. 进阶：`mass-task-mapping`、`speed-training-plan`；旁支通用工具 `mind-map`；
   全程用 `four-step-flow` 串成一条线。

## 背景：作者的记忆模型（参考内容，非操作依据）

对应 `references.md` **r01 / r02**。这部分**不改变任何操作**，只解释作者为什么这样设计配方；
其中带 † 的是作者自造或转述、**无出处的解释框架**，不得对外当作科学结论。

- † **记与忆分开**：外界事物（原块）刺激感觉神经（感块）进入大脑储存（记块），需要时被提取（忆块）。
  “记了”不等于“提得出”，两者还可能失真——这是本书把方法拆成“记法”与“复习/提取线索”两半的理由。
  （P012–P014；术语仅此一节出现，非标准心理学术语）
- **再现 vs 再认**：识记-保持-再现＝回想记忆（要自己说出来）；识记-保持-再认＝认知记忆（一看就认得，
  如选择题）。作者落点：**通过复习可以把再认提升为再现**（P013）。
- **三种记忆的时长/容量/遗忘原因**（作者转述口径，P015–P016）：瞬时记忆（图像 0.25–1 秒、声像约 2 秒，
  因痕迹消失而忘）；短时记忆（≤1 分钟，广度平均 7±2，因干扰而忘）；
  长时记忆（相对永久、容量大，**因缺乏回忆线索而忘**）——最后一句是全书“必须给线索（桩/码/关键词）”的依据。
- **五种记忆内容**（P014–P015）：形象 / 情景 / 情绪 / 语义 / 动作。作者真正用到的是“形象”
  （图像化联想）与“情景”（地点桩天然带情景），其余三类未展开为配方。

## 数据与限制（引用本书数据时必须带上）

对应 `references.md` **r03**。

- 作者转引的艾宾浩斯遗忘率：20 分钟后遗忘约 41.8%、1 天剩约 33.7%、1 个月剩约 21.1%（P028–P030）。
- 同处引用：“记住 12 个无意义音节平均需重复十五六次；记忆六首诗的 480 个音节平均只需重复 8 次”（P029–P030），
  用来说明**有意义材料远比无材料好记**。
- **必须保留的限定（作者本人写明）**：以上数据“是对无意义音节而言”，且“不同的人有不同的遗忘曲线”（P031）。
- 由此推出的六次复习间隔（10 分钟 / 1 天 / 1 周 / 1 个月 / 6 个月 / 1 年，每次 2–10 分钟）
  在**本包中被定位为“可用的经验排程”**，不是科学常数；`review-scheduler` 卡片与 `needs-review.md`
  NR-05 已同步这一口径。
- 同理，作者给出的训练目标（扑克读牌 ≤1 分钟、26 桩 × ≥10 组、每天早晚各 1 小时、一个月 2 分钟/副；
  数字 40 位起步、每天 2 小时、一个月 5 分钟 100 位）是**经验值、无样本支撑**（`speed-training-plan` 的 B 段）。
- 作者引用的其他基础口径（短时记忆 7±2、长时记忆容量无限）在书中被当作“可以背整本书、随机提取”的
  可行性证明，属**推断而非实证**（阶段 0 批判节已记录）。

## 本包不覆盖（避免误用）

- 理解、推导、鉴赏、写作类学习任务（作者自设边界：纯记忆知识点 ≤30%，单词约 70% 适用）
- 任何“取值”：数字码表、字母编码表、扑克牌码、二进制对照表、元素含量、税率与法条内容
- 儿童英语发音教学中的谐音替代；病理性记忆问题的评估或干预
- “永久记忆”“一字不漏”的承诺（本书验收线是回忆 80%–90%）
