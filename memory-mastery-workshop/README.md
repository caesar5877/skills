# memory-mastery-workshop — 安装说明与版本状态

> 本目录是 cangjie-skill 编译产物的**安装副本**（single 模式：1 个可发现入口 + 18 张内部能力卡）。
> 入口：`SKILL.md`（宿主按 name/description 发现；再按其中「能力路由」表加载 1 张卡）。

## 版本状态：自测通过的草稿（不是已验收版本）

- **来源**：胡庆文《记忆达人教你神奇记忆术》（中国纺织出版社 2017.3，ISBN 978-7-5180-3153-5）。
  本包是对**用户提供的扫描版 PDF** 的归纳与改写；页码一律为 PDF 页码 P0NN（印刷页 ≈ PDF − 19）。
- **已经自测通过的**：Bundle/卡片结构完整性、卡级可达（**确定性代理**，非真实模型）、
  14 条代表任务的交付物与 109 条机械断言、35 条原文引文的字 n-gram 落位、诱饵拒答条款覆盖。
- **尚未验证的（重要）**：真实模型**会不会触发本包、会不会选对卡**完全未测；没有独立盲测（干净上下文执行者）、
  没有「不用卡」的基线对照；用于调优的保留集已被看过，故 20/21 的可达命中是训练集内成绩，不是泛化能力。
  输出任务的执行者与判分标准的撰写者是同一个蒸馏流程。
- **已知风险（摘要，完整表见来源仓库 `books/memory-master/.cangjie/evals/known-issues.md`）**
  - KI-01 归因类请求（"用了 X 方法没效果，是方法还是我没做对"）在代理路由下会被领域卡抢走；
    入口已加「归因先于重选」判停条款，但模型是否遵循未验证。
  - KI-02 两条路由分数差 <0.005（思维导图/画面排障），换宿主或换模型容易翻车。
  - KI-03 真实触发精度未测；KI-04 保留集污染；KI-05 无 without_skill 基线。
  - KI-06 `speed-training-plan`（数字/扑克训练计划）未做任何代表任务实测。
- **因此**：可用于自己练习、查阅与回归测试；**不要**把它当"已验证有效"的方案对外承诺效果。
  包内 `references/overview.md` 的「本包当前状态」一节带同样口径（随包分发）。

## 内容清单

- `SKILL.md` — 触发与不触发、核心原则、能力路由表（18 行）、加载规则、边界与判停
- `references/overview.md` — 书级概览、能力地图、推荐学习顺序、数据与限制、来源与可信度、当前状态
- `references/glossary.md` — 27 条术语词典 + 码表骨架 + 缺口清单
- `references/cheatsheet.md` — 一句话决策规则速查
- `references/capability-index.md` — 完整意图与关键词索引（路由表未命中时先查这里）
- `references/capabilities/*.md` — 18 张能力卡（R/I/A1/A2/E/B 六段）
- `BUILD_MANIFEST.json` — 发布哈希与决策记录（run `run-20261126-143127-9308f8`）

## 本包刻意不提供的东西

- 原书任何**取值**：00–99 码表、字母编码表、扑克牌码、二进制对照、元素含量、税率与法条内容
  （扫描版表格 OCR 受损，且部分属外部/时效事实）。需要的是"怎么自建 + 怎么校验"，不是抄表。
- 效果承诺：作者的成绩与训练目标（2 分钟/副、5 分钟 100 位等）是**自述与经验值**，无样本支撑。
- 卡内为可执行而设的阈值（如 >60 位上桩、每组 10–20 词、≤7 项串连）属**本包约定**，原书未给。

## 更新 / 回滚 / 卸载

- **更新**：在来源仓库改 Bundle 后重新编译（`cangjie.py compile --bundle books/memory-master/.cangjie/capabilities
  --out out/memory-mastery-workshop --output single --yes`，Windows 下先 `set PYTHONUTF8=1`），
  再整目录覆盖本目录。**不要**直接手改本目录内容：`BUILD_MANIFEST.json` 里的哈希用于发现本地手改。
- **回滚**：来源仓库 `books/memory-master/.cangjie/snapshots/`（若存在历史快照）或重新编译。
- **卸载**：删除本目录即可（不要与同一本书的其他形态同时安装，避免两套 description 竞争触发）。
- 本 README 为安装时附加说明，不属于编译产物；重新覆盖安装后如被清掉，可再放一份。
